开图 iPhone 隐私政策

适用于「人生开图」iPhone App，包括 TestFlight 测试版。

更新：2026 年 10 月 22 日。适用于「人生开图」iPhone App 0.7.2，包括 TestFlight 中的问问功能。

开发者不提供接收个人资料的开图云端服务器。你可以只在手机上使用；连接云盘、使用 AI、语音识别或联网地图时，相关服务会按你的操作接收必要的数据。

资料与凭据存在哪

  • 手机： 本机档案、笔记、待办、未发送文字草稿、对话历史，以及已连接资料位置的缓存和待交出记录，保存在 App 的本机存储中。
  • 你选的资料位置： 连接文件夹、iCloud、私有 GitHub 仓库或 Google Drive 后，相关资料由对应服务存放。保存到手机、交出文件和收到处理回执是不同状态。
  • 凭据： AI Key 和 GitHub 凭据保存在本机钥匙串，Google 登录由 Google Sign-In SDK 管理。凭据用于你选择的服务，不发送给开图开发者。

问问和给 AI 的资料

问问是可选功能，需要你配置所选服务商的 Key，调用费用与额度由该服务商账户承担。当前提供 DeepSeek、Kimi、智谱和 OpenAI 选项。

你发起问答时，问题、工作区规则、上下文摘要、读取到的资料片段和最近对话会发送给所选 AI 服务。明确选择并发送的图片会发送给支持图片的模型。服务商按自己的隐私政策处理这些请求。

「给 AI 的我」先由你审阅和确认，再复制或导出。默认分享不包含敏感项；改变选择后需要重新确认。模型提出的建议不是已保存事实，只有你明确采纳才会写入资料。

照片、相机与语音

  • 照片足迹： 经系统授权后，扫描允许访问照片的拍摄时间和位置元数据，不扫描照片像素。保存城市中心和推断经历，不保存原始精确 GPS 或照片资产标识；推断经历仍需本人核对。
  • 相机与图片附件： 只有你明确使用拍摄或选图入口才读取相应图片。添加附件不等于发送给模型，发送给模型是另一次明确操作。
  • 语音： 由 Apple 系统语音识别转写，支持时优先在设备上处理，否则可能由 Apple 的识别服务处理。转写可以编辑，明确保存后才进入资料。App 不保存录音。

健康与日历

健康权限由你在系统中选择，App 只读 Apple 健康，不向其中写入数据。授权范围取决于你使用的新手引导或健康同步入口。

新手引导的健康原始输入另存手机，不包含在默认背景分享中。另行启用健康同步时，获准数据会以原始样本格式交到你选择的资料位置或接收地址，例如你自己的 Google Apps Script。开发者不接收这些样本，也不用于广告或出售。

开图中的日程记录与 Apple 日历是两个存放位置。只有你使用日历联动并授予相应系统权限时，App 才会写入「开图」日历。本机保存不代表已经同步到系统或电脑。

GitHub 与 Google Drive

GitHub 官方登录或 Token 只用于获准的资料仓库。Google Drive 请求完整 Drive 权限：Google 层面的授权可读写整个 Drive，App 自身将资料操作限定在你选择的开图目录。

Google Drive 在首轮公开测试中为受限功能。如果 Google 项目仍处于 Testing 状态，只有登记的测试账号可以授权；TestFlight 邀请不会自动赋予 Google 授权资格。

断开本机连接不会删除远端资料，也不等于撤销远端授权。你可以在 Google 账号连接设置或 GitHub 已授权 App中管理或撤销授权。

地图、诊断与反馈

地图使用 MapLibre，并可能向 OpenFreeMap / OpenStreetMap 相关图块服务和 Terrain 地形数据服务请求样式或图块。这些服务会接收到正常网络请求信息，例如 IP 地址和所请求的地图区域。足迹位置来自资料中的城市，不使用相册原始精确 GPS 绘图。

App 没有广告，也未接入第三方行为分析或广告追踪 SDK。TestFlight 反馈和 Apple 提供的崩溃诊断适用 Apple 的相关说明。你主动发邮件或提交 Issue 时，开发者会收到你提交的内容；请不要在公开反馈中放入 Key、私人对话或健康原文。

你的选择与删除

  • 本机建档和记录不要求注册开图账号；AI、云盘和系统权限均按所用功能选择。
  • 在系统设置中关闭照片、健康、相机、麦克风、语音或日历权限，停止相应访问。
  • 在 App 中删除 AI Key、退出第三方登录或断开资料位置；需要远端撤权时使用该服务的账号设置。
  • 卸载 App 会移除 App 的本机文件，但不等于删除云端副本、系统备份或撤销第三方授权。云端文件由你在所选服务中管理。

儿童与政策更新

开图不面向 13 岁以下儿童。数据处理方式改变时会更新本页和日期；新增数据去向会在相应功能中说明。
