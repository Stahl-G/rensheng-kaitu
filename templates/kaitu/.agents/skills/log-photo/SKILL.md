# 记录体态照片

## 步骤

1. 先确认图片已作为本机文件提供，不能只用云端缩略图路径。
2. 运行 `kaitu photo list --json-out`，核对已有日期与姿势。
3. 从用户描述识别 front、side、back 或 other。
4. 不明确时询问姿势，用户无所谓可用 other。
5. 原图支持 JPEG、PNG、WebP；HEIC 在 macOS 由系统转换。
6. 其他系统的 HEIC 先请用户导出 JPG，不重命名伪装格式。
7. 命令按文件头识别，别只依据扩展名判断能否导入。
8. 一张照片不超过 25MB。
9. 拍摄时间由用户提供时使用带时区偏移的 ts。
10. 未提供则使用现在，不根据 EXIF 或文件修改时间补造拍摄日期。
11. 示例命令：
```sh
kaitu photo add "inbox/body.jpg" --pose front --notes "晨起拍摄"
```
12. 补记可加 `--ts "2026-10-14T08:00:00+08:00"`。
13. 命令负责复制到 health/files/photos/、记录并生成版本，不手改 JSONL。
14. 运行 `kaitu photo list` 核对返回的 id、日期与姿势。
15. 用 `kaitu ui` 打开健康 → 身体指标，看照片墙。
16. 比较时选两个日期，优先选择同姿势、近似光线和距离的照片。
17. 需要删除用 `kaitu photo rm <id>`，文件与记录一同删除，可从历史恢复。
18. 不要从照片推断精确指标，体重与体脂仍用实际测量记录。

## 确认点

日常照片记录直接保存；批量导入先展示日期与姿势清单供确认。

## 交付

报告保存日期、姿势与 id，引导用户在工作台对比。
