# 整理今日动态

## 步骤

1. 读取 feed/feeds.json 的订阅列表和关键词。
2. 读取最近的 feed/digests/，避免重复推送旧事。
3. 按用户时区确定今天日期。
4. 使用 Agent 自己具备的联网能力读取来源，或整理用户贴来的链接和正文。
5. 当前会话不具备联网能力时，明确说明并请用户提供内容。
6. 不要调用尚未实现的 `kaitu feed fetch` 或编造已抓取结果。
7. 逐项核对发布与事件日期，区分旧闻新发与当天事件。
8. 优先使用来源正文，标题不足以支持结论时不强写。
9. 按 feed/feeds.json 的关键词筛选，再考虑用户当前目标。
10. 每条写发生了什么、与用户的关系和原文链接。
11. 同一事件合并多来源，保留关键分歧。
12. X 内容仅在实际可读时使用，不假装能访问账户时间线。
13. 外部 Agent（如 Grok Bot）可通过 MCP 的 write_digest 送入 X 或新闻简报。
14. 远程连接方式见项目 docs/remote-agents.md，以对方官方文档为准。
15. 写入前读取当天简报，保留其他 Agent 已整理的有效内容。
16. 写 `feed/digests/YYYY-MM-DD.md`，标明实际来源和资料截止时间。
17. 来源不足时说明缺口，不用空泛内容凑条数。
18. 运行 `kaitu validate`。
19. 运行 `kaitu snapshot -m "Agent 整理了今日简报"`。
20. 引导 `kaitu ui` 在动态页阅读。

## 确认点

读取和整理用户提供或可访问来源无需确认；不代用户发布或联系他人。

## 交付

给出简报路径与最值得关注的几条内容，说明未能读取的来源。
