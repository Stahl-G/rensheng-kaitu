## 现在要做成什么

按 PRODUCT.md「本轮优先级与验收」推进：独立 Kaitu.app 与 DSH 插件都提供今天、开图、资料、问问四个入口，新用户搬进资料就看得见、不填 Key 也能整理出一个下一步，状态如实。

## 一直有效的方向（2026-10-15 定）

- **轻量优先**：默认只装一个开图，不要求 Docker、数据库或其他服务。能当库嵌入的开源项目直接嵌入；要部署服务的项目只做「已有就接上」的可选连接。
- **只做两样东西**：资料文件夹加 `kaitu` 命令（Agent 读它就知道情况），以及人打开就知道情况的界面。
- **不自己造引擎**：饮食识别、健康数据、日历、订阅源、对话、记忆提取都用现成项目或交给 Agent。
- 只为真实业务错误补必要测试。保留用户数据、已有功能、记录 ID 与当前数据规范。
