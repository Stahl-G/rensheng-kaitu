name: kaitu-project-memory
description: 开始工作时读开图共享记忆和相关项目，结束时更新项目进度并写一份交接。
---

开始：在记忆仓库 `git pull`，按 AGENT-README.md 的顺序读档案、记忆和较新的交接；当前工作涉及项目时读该项目的 STATUS.md 和 log.md。

结束：更新这个项目的 STATUS.md（做到哪、卡在哪、`next`）并在 log.md 记一条；在 `handoffs/` 新建一份交接（做了什么、当前下一步、未决），按 AGENT-README.md 更新手机内容，提交并推送；冲突保留两边。档案、偏好和目标不直接改，建议写进 `inbox/agents/`。
