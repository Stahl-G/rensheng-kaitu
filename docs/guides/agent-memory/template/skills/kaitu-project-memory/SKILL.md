先读记忆仓库 AGENT-README.md，保护本地变更并安全拉取；读取 me/profile.md、me/rules.md、memory/MEMORY.md 和更新的 handoffs，目标按需读。有选中项目时再读对应 STATUS/log；零项目直接跳过，不要求发现本机代码项目。

事实引用实际来源，候选不当已采纳。普通 Agent 只新建唯一 inbox/agents/*.note.md 或 handoffs/<真实时间>-<agent>-<唯一后缀>.md，沿用 agent/at/follows 与“做了什么 / 当前下一步 / 未决或需要用户”。保留正式档案、记忆、目标、规则、快照及已有配置。授权范围内正常同步并回读远端；冲突保留双方，不强推。

不安装 runtime、不修改全局设置、不扫描其他设备或账号、不读取凭据。当前记忆仓库的根 AGENTS/CLAUDE 就是薄入口；项目技能是可选适配，保留同名冲突，不作为个人记忆初始化条件。
