# 开图私人共享记忆

一个私有 GitHub 仓库存你的档案、偏好、目标和项目进度，换设备、换 Agent 都能接着用。有开图 App 或 kaitu 命令就用它；没有的话，Agent 用普通 Git 和官方 gh 也能建。

把下面一段交给能操作文件和终端的 Agent：

```text
请读 https://github.com/Stahl-G/rensheng-kaitu/blob/main/docs/guides/agent-memory/INSTALL.md ，照做，帮我建开图私人共享记忆。
```

另一台设备或新的 Agent：

```text
请读 https://github.com/Stahl-G/rensheng-kaitu/blob/main/docs/guides/agent-memory/ADD_DEVICE.md ，照做，接上我的开图私人共享记忆 <仓库地址>。
```
