# 实际使用顺序

1. 复制初始化入口。Agent 自动检查工具、登录、账号和安全新目录，默认 PRIVATE kaitu-ai-memory；它不先要求发现或选择本机项目。
2. 从已知对话整理低敏感背景、偏好和目标；缺少时短问，可全部跳过。你可以先建立空骨架，之后再补个人内容，零项目不会阻塞。
3. 如果现在想加项目或资料，可以指定当前机器内容、GitHub repo、文档等；本机发现只是可选项。Agent 自己提取带来源的摘要，不扫其他设备/账号，不让你填写文件清单。
4. 在个人内容写入与上传前一次核对精确私人目标、记忆目录、偏好/目标/规则、可选项目、来源和排除范围。已有任何仓库/目录保留，不覆盖或自动迁移；官方授权及系统权限正常处理。
5. 初始化完成后回读个人入口与远端提交。零项目时 projects 只有 module.json，goals/ongoing 可为空，me/memory 和当前 Agent 薄入口应完整；不得残留必选 example-project 或虚构个人内容。
6. 把自动生成、填好实际地址的提示词交给第二设备或全新 Agent。它读取同一 me/memory 及按需目标、交接，项目有则读、没有跳过，继续已给任务。观察偏好、目标和真实下一步是否正确接续，写回与远端回读按实际情况记录。

流程不要求 App、runtime、代码项目、合成任务或双 Agent 考试。目录和文件存在只能证明骨架，不代替真实理解、任务结果及同步证据。
