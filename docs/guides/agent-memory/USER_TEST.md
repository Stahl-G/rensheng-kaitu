# 你亲自测试：一个库，多个 Agent

只由第一个 Codex 初始化一次。之后 Claude、Devin、Cursor 或另一个 Codex 都走“接入已有库”，各用全新会话和独立 clone 目录，串行执行。不要让它们分别建库，也不要共用一个有未提交改动的 clone。

## 第一个 Codex

复制 [短初始化入口](COPY_TO_YOUR_AGENT.md)，再补这一句测试范围：

```text
本轮只做合成测试：请新建一个空的合成项目目录和一个空的记忆目录，不接我的真实工作区。私库拟名 kaitu-ai-memory-test，精确 owner/repo 仍先让我确认；只由你初始化这一次。初始项目叫 Synthetic parser，历史失败设定是“曾误按逗号理解样例，尚未复核”，阻塞是“等待后续 Agent 独立核验”。把合成样例 name|count / sample|2 放进一份唯一 inbox/agents/*.note.md，来源标为用户确认的测试夹具；不得当作真实历史执行结果。首份交接列出三项待核验：分隔符、数据行数、字段名。生成填好私人仓库 URL 与项目 slug 的接入提示词，让后续 Agent 只从库里读背景，每次核验一项、在新 follows 交接里写实际结果与剩余完整清单。不要上传合成项目目录本身、其他项目或真实资料，也不要配置 OAuth。
```

先确认目标名称、PRIVATE 和文字范围，再批准创建与推送。初始化后保留以下验收凭据：精确 repo、项目 slug、首份 handoff 路径、远端提交与生成的接入提示词。不要把 token 或真实资料发回。

## 其他 Agent 串行接入

把第一个 Codex 生成的实际接入提示词发给 Claude；缺失时用 [短接入入口](COPY_TO_NEXT_AGENT.md)，让它询问唯一 repo 和 slug。不要再发初始化入口。

1. Claude 在自己的新目录 clone 同一个测试记忆库，不给它额外项目背景。它应先引用 STATUS/log/最新交接，复述失败尝试、阻塞及下一步；再完成一项合成核验，写唯一 follows 交接，正常同步。
2. 确认 Claude 推送完成后，再让 Devin 在独立目录重复接入。它应该读到 Claude 的结果并处理下一项，不能只复述初始快照。
3. 确认 Devin 推送完成后，再让 Cursor 接入自己的 clone，读取前序结果并处理剩余一项。没有未完成任务时就报告，不编造新任务。
4. 回到第一个 Codex，让它安全拉取后读回三份新交接，引用各来源复述已完成项和剩余事项。初始 STATUS/log 未自动改写是普通追加角色的预期行为。

每步检查：独立目录、同一 repo、无重复初始化、引用的前序路径正确、合成核验结果有样例依据、follows 存在、完整下一步没有丢失、普通推送成功。只按实际情况记录“通过／失败／未测”；技能安装、CLI 返回成功或文件存在都不能代替接续结果。

## 最后可选：两个 Agent 同时追加

串行测试通过后，才在两个独立 clone 中同时新建各自唯一命名的 handoff。先记录创建与普通推送结果；有拒绝或冲突就保留双方并报告，不强推、不删文件。除非实际走完并核对远端两份内容和语义，否则不要把这一小步称为“完整并发合并通过”。

本轮由你亲测，维护者没有启动自动模型验收，没有替你创建真实测试仓库或设置 OAuth。无需桌面包。
