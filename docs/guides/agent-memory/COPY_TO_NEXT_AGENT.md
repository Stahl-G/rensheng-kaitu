# 复制给第二设备或全新 Agent

个人共享记忆可零项目初始化；完整规则固定到包含零项目模板的提交。

```text
请读取并执行 https://github.com/Stahl-G/rensheng-kaitu/blob/379a7656eeaebbe01523f4dc8a6357ac6c514253/docs/guides/agent-memory/ADD_DEVICE.md ，接入我的私人开图共享记忆。自动检查当前环境、工具和已有登录，采用已给出的真实仓库地址；缺失时核对默认 kaitu-ai-memory，仅账号或目标有歧义才问。保留已有目录，核实私人目标后安全克隆，读取 me 档案规则、memory 索引和最新交接，按需读目标；没有项目直接跳过，不要求我补项目或现状。使用同一份当前 Agent 薄入口，继续已给任务，不装新运行时、不改全局设置。个人内容新增或范围扩大时一次确认，授权范围内正常同步并回读，冲突保留双方；不扫描其他机器或账号，不把文件存在当成任务已完成。
```
