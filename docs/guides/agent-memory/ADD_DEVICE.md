# 第二设备或全新 Agent

优先使用初始化助手填好的完整版本。只有未生成时，复制下面一次，并向 Agent 提供已确认的私人仓库 URL；它应主动询问缺失项，不能猜仓库。

```text
请把这台设备或这个全新 Agent 接到我的开图私人项目记忆。我会提供准确的 PRIVATE_REPOSITORY_URL 和项目 slug；缺失就先问我，不猜目标。只接这一份记忆和我指定的一个项目，不扫描其他项目，不复制源码、个人资料或凭据，不要求 App、特定操作系统、Node、Python、MCP 或新 runtime。先检查 Git/官方 gh；缺失或未登录时说明官方流程并让我正常确认，不索取密码、token、验证码或私钥，不改全局配置。

如果已有 kaitu 或源码 pnpm kaitu，先核 --help 和实际目录，仅在帮助成功时可选使用；旧包装器失效则说明，不假设 npm/npx 已发布。没有 CLI 就继续普通 Git 路径，不因此阻塞。用官方 gh 核对我提供的精确仓库及 PRIVATE，在我确认的全新空目录只克隆这一仓库，不覆盖已有目录；已有目录有改动则保留并解释，不 hard reset、不强推或删除重来。

读取 AGENT-README.md；按它的顺序读最新每日整理（没有则 OVERVIEW）、更新的 handoffs/ 与 inbox/agents/、指定项目 projects/<slug>/STATUS.md/log.md/notes.md。候选原文不是已采纳事实，初始摘要不是自动刷新的现状。引用具体日志和最新交接，最多五条说明项目做到哪、失败尝试、阻塞、完整下一步和来源；没有证据就说未知，不替我编结果。先让我确认你是否接对项目，然后只执行我确认的一项小任务。

普通 Agent 不改初始 STATUS/log/OVERVIEW、目标、规则或正式记忆。结束时只新建唯一 handoffs/<真实时间>-<agent>-<唯一后缀>.md，沿用 agent/at/follows 与“做了什么 / 当前下一步 / 未决或需要用户”，follows 指向刚读的真实前序；同时分支交接都读，保留双方。候选写唯一 inbox/agents/*.note.md。没有整理员就保留这些文本供下个 Agent 读，不假称收件箱处理、快照回写、App 索引或手机已完成。

若要安装当前项目薄技能，先让我指定该项目代码目录，展示路径/内容并正常审批；保留原 AGENTS/CLAUDE/README 与同名冲突，不修改全局设置，不安装依赖缺失 CLI 的技能。可直接按本提示词工作，技能文件存在不算接续验证通过。

普通 Git 路径先检查变更、保护本地工作，再安全拉取；只暂存本次新建的记忆文件，检查暂存 diff 和凭据模式，正常提交推送并核验远端提交，冲突让我选、不丢任何一方。已有 CLI 路径只用已验证入口 backup sync/status 并显式 --dir <实际记忆工作区>，不同时用第二套同步方式写同一本机工作区。最后回读新交接并报告实际完成的工作、远端同步状态，以及仍待我验证的事项；不向其他线程发消息、不把普通文件测试冒称两个 Agent 的实际验收。
```
