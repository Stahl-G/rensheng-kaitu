# iPhone 界面设计验收：0.7.0 (6)（2026-10-18）

对象：iPhone Duo 外屏上的今天页和开图页（`kaitu-ios`，0.7.0 (6)）。对照画板见本目录 [README.md](README.md)。
结论：功能在，样式回到了系统默认，并且把原始数据直接显示了出来。设计方向不改，按下面逐条收紧。

## 先定三条规则（以后所有界面都适用）

1. **字号只用五档：** 大标题 34，标题 22，正文 17，次要 15，说明 13。用 SwiftUI 的 `.largeTitle` / `.title2` / `.body` / `.subheadline` / `.footnote`，跟随动态字体，不写死别的大小。
2. **界面上不出现原始数据：**
   - 日期统一走一个格式化函数：今天、明天、昨天用文字，其他写「10月19日」，带星期写「10月18日 · 周日」，时间写「07:30」。不出现 `2026-10-19` 这种 ISO 日期。
   - 不显示内部代号：快照里的 `section`（today / me / health / projects / feed）只拿来分组和选图标，不当文字显示。要标来源时显示 `module`（模块或项目名）。
3. **颜色只用资源目录里的命名颜色**（README「颜色与字号」那一节），地图也一样。
