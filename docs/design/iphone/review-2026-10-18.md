# iPhone 界面设计验收：0.7.0 (6)（2026-10-18）

对象：iPhone Duo 外屏上的今天页和开图页（`kaitu-ios`，0.7.0 (6)）。对照画板见本目录 [README.md](README.md)。
结论：功能在，样式回到了系统默认，并且把原始数据直接显示了出来。设计方向不改，按下面逐条收紧。

## 先定三条规则（以后所有界面都适用）

1. **字号只用五档：** 大标题 34，标题 22，正文 17，次要 15，说明 13。用 SwiftUI 的 `.largeTitle` / `.title2` / `.body` / `.subheadline` / `.footnote`，跟随动态字体，不写死别的大小。
2. **界面上不出现原始数据：**
   - 日期统一走一个格式化函数：今天、明天、昨天用文字，其他写「10月19日」，带星期写「10月18日 · 周日」，时间写「07:30」。不出现 `2026-10-19` 这种 ISO 日期。
   - 不显示内部代号：快照里的 `section`（today / me / health / projects / feed）只拿来分组和选图标，不当文字显示。要标来源时显示 `module`（模块或项目名）。
3. **颜色只用资源目录里的命名颜色**（README「颜色与字号」那一节），地图也一样。

## 外屏和内屏切换不连续

第二张截图是展开过程中的一帧：整个画面糊掉、内容重新排了一遍。系统在尺寸变化时会先拿旧画面的截图顶着，等 App 排好新布局再换上；App 如果把整棵视图换掉重建（地图重新加载、列表回到顶部），这一下就会很明显。广告里那种连续感要靠下面几条：

1. **视图树不换，只换排法。** 不要写成「窄屏用 TabView，宽屏用 NavigationSplitView」这种二选一（`if sizeClass == .compact { … } else { … }`），切换时会整棵重建。用同一个根视图，按宽度改布局（`ViewThatFits` / 自定义 `Layout` / `AnyLayout` 在 `HStack` 和 `VStack` 之间切）。
2. **地图只有一个实例。** 外屏时地图是今天下面的一张卡，内屏时同一个地图铺满。同一个 `MKMapView`（或 SwiftUI `Map`）只改外框尺寸，不重新创建、不重新加载瓦片；路线和地点的叠加层保留。
3. **东西从哪来到哪去。** 用 `matchedGeometryEffect` 把三样东西连起来：地图卡 → 全屏地图；「最重要的一件事」卡 → 右侧面板里的那一行；城市一排 → 底部城市一排。展开时它们是移过去、放大过去，不是消失再出现。
4. **状态全在共享模型里。** 选中的城市、滚动位置、正在看的标签都放在同一个 `@Observable` 模型里；外屏在看开图，展开后就停在开图，选中的城市不变。合上时反过来。
5. **尺寸变化时不做重活。** 不在 `onChange(of: size)` 里重新读快照、重算路线、重新请求地图区域；只做布局。重活在启动和快照变化时做完。
6. **动画用系统给的那一次。** 跟着系统的尺寸过渡走，不额外加自己的转场；需要时用 `.animation(.smooth, value: layoutMode)` 让同一帧内的布局变化平滑。

用户已确认这几条（2026-10-18）。效果见 `Unfold.dc.html`：点「展开 / 合上」看每样东西从哪移到哪，「慢速 ×3」看清过程；时长和曲线跟系统的尺寸过渡走，画板里的 600ms 只是示意。

验收：模拟器打开「慢速动画」展开、合上各三次，录屏放进 PR；地图不闪、不重新加载，选中城市和滚动位置不变。iPhone Duo 和 iOS 27 的折叠新接口（如果有）要先核对苹果文档再用，没核对过的不依赖。

## 切换仍然突兀：原因和改法（按 kaitu-ios 代码）

看的是仓库里能读到的 `codex/ios-device-0.6.0-4`（`kaitu/Views/PhoneRootView.swift`、`MapPage.swift`）；本地 0.7 如果已经改过结构，以本地为准再对一遍。

### 原因

1. **根视图是二选一。** `if sizeClass == .regular { NavigationSplitView … } else { TabView … }`：展开那一刻，整棵树从标签栏 + 导航栈换成侧栏 + 分栏，导航栏、大标题、侧栏都是系统各自的动画，跟内容不同步，看起来就是「换了一个界面」。
2. **地图被搬到另一棵树里。** `MKMapView` 由 `model.mapSurface` 持有，这一点是对的；但它从 TabView 里的 `MapPage` 被拆下来、挂到分栏里的 `HStack`，中间有一帧没有地图。
3. **尺寸变了，地图范围不跟着变。** `showAnnotations` 只在第一次加载时调用，之后窗口变宽变窄，地图中心和缩放不变，所以外屏只看到一截路线（第三轮截图），展开后路线又挤在一角。
4. **右边那一列不是同一个视图。** 宽屏里的 `TodayPage` 和窄屏 TabView 里的是两个实例，滚动位置和展开状态各算各的。

### 改法

```swift
struct PhoneRootView: View {
    @State private var model = PhoneModel.shared
    var body: some View {
        GeometryReader { proxy in
            let wide = proxy.size.width >= 700          // 按实际宽度，不看方向
            ZStack(alignment: .topLeading) {
                // 1. 地图永远是第一层、同一个视图，只改外框
                ProgressMap(surface: model.mapSurface, snapshot: model.map)
                    .frame(width: wide ? proxy.size.width : proxy.size.width - 32,
                           height: wide ? proxy.size.height : 300)
                    .clipShape(.rect(cornerRadius: wide ? 0 : 24))
                    .offset(x: wide ? 0 : 16, y: wide ? 0 : 116)
                // 2. 窄屏整页就是宽屏右边那一列：同一个视图，只改位置
                PageColumn(page: model.page)              // 城市一排、接下来往哪走、最重要的一件事…
                    .frame(width: wide ? 390 : proxy.size.width)
                    .offset(x: wide ? proxy.size.width - 390 - 16 : 0)
                // 3. 导航：自己画的标签栏和顶部胶囊，同一个模型，各自淡入淡出
                TabBar(selection: $model.page).opacity(wide ? 0 : 1)
                TopPill(selection: $model.page).opacity(wide ? 1 : 0)
            }
            .animation(.smooth, value: wide)
        }
    }
}
```

- 不用 `TabView` / `NavigationSplitView` 做根，也不在根上用系统导航栏的大标题；标题、标签栏、胶囊都自己画，跟内容一起动。
- 视图里不要出现 `if wide { A } else { B }` 这种会换掉身份的写法，只改 frame、offset、opacity。
- 地图外框一变就重新取景：在 `MKMapView` 的 `layoutSubviews`（或 SwiftUI `onGeometryChange`）里用 `setVisibleMapRect(_:edgePadding:animated: false)` 把全部地点放进可见区域；宽屏的 `edgePadding.right` 等于右边那一列的宽度，让路线落在左边露出来的那块。
- 右边那一列宽度固定为外屏宽度（以外屏实际宽度为准，不写死 390），滚动位置天然保留。
- 尺寸变化时只做上面这些；不重新读快照、不重新加叠加层（现在 `update` 用 `generatedAt` 判断，这一点保持）。

### 验收

模拟器打开「慢速动画」，录展开、合上各三次：地图始终在、不闪；外屏和内屏都能看到全部路线；右边那一列的内容和滚动位置在展开前后完全一样，只是多出了左边的地图。对照画板：外屏 `Map.dc.html` 的上半部分，展开 `WideMap.dc.html`，过渡 `Unfold.dc.html`（右栏按本节改为「整列平移，不重排」）。
