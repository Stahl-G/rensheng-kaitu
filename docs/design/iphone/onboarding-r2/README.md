## 0. 结论

这一轮的流程比 PRD v1 更好，PRD 已经按它改成七屏：一件事 → 说一句 → 我的一页 → 整理给我的 AI → 贴回来 → 地图 → 今天。健康、照片、搬记忆这些移到上手之后，在「今天」里慢慢补。

第一轮要求的深色、放大字号、减弱动效、375×667、加载 / 失败 / 无地点几种状态都补上了，演示工具栏的做法很好，后面几轮保持。

## 1. 保留

| 地方 | 为什么好 |
|---|---|
| 屏 1「最近有什么事，你想理一理？」+ 六个主题（含「还说不清」）+「我想直接说一句」 | 不要求先定人生主线（BRAND.md 第 9 节） |

| 「整理给我的 AI」：选 AI、勾选这次带什么、完整预览、点了才复制 | 就是 BRAND.md 第 4 节要的范围选择，直接作为 PRD 屏 4 |

| 示例小林 杭州 → 南京 → 上海，加「同城停留：周末散步的一小圈」 | 一座城市也能有内容 |

## 2. 要改的

| # | 问题 | 怎么改 |
|---|---|---|
| 1 | **少了「贴回来」**：只能复制出去，循环断在一半 | 新增 PRD 屏 5：系统「粘贴」按钮做主按钮（第一轮反馈 3.4）→ 认出 AI 给的 2–3 条路 → 点一条 → 核对目标、现状、下一步 → 「采纳这个下一步」。画齐：认出、认不出（「格式对不上，已原样存下」）、剪贴板没东西、我手动粘贴 |
| 2 | **只带主题和一句原话，AI 认识不了你** | 「我的一页」原话下面加三个可跳过的小项：怎么称呼你、现在住在哪个城市、现在主要在做什么（单选：上学、上班、自己做事、在找工作、在找方向、照顾家庭、其他）。点开是半屏弹层。填了的在屏 4 默认勾上 |
| 3 | **城市默认不勾** | 城市是 AI 认识人的基础，默认勾。默认不勾、带小锁的是：钱与关系、标为敏感的记忆、涉及他人的内容、录音转写 |
| 4 | **界面里出现「共同底稿」** | BRAND.md 定的是内部用词，界面说「我的资料」。「我的共同底稿」→「我的资料」，「从共同底稿里选」→「从你的资料里选」 |
| 5 | **街道层还是 OSM 现成瓦片**，满屏街道名，深色下很脏 | 城市镜头也用纸本样式：只留海岸线、水系、国界和地形阴影，道路和地名默认关，城市名由开图自己画。设计稿里用静态图示意即可（第一轮反馈 3.2） |
| 6 | **页脚旧口号**「AI 可以换，你的积累会留下」 | 换成「让每个 AI，一读就认识你」 |
| 7 | **六个主题卡颜色偏多** | 降低饱和度，或统一成纸色卡片 + 一个小色点，避开 BRAND.md 说的幼态手帐 |
| 8 | **每屏说明小字太多** | 原型里的「原型不会保存」类说明全部移到演示工具栏；产品画面每屏最多一行信任说明 |

另外三处补充：

- **目标 AI** 加上 DeepSeek、Kimi、元宝（新手常用），保留「其他」。
- **复制之后**画三步示意：打开{豆包}粘贴发送 → 长按回答点复制 → 回到开图点「粘贴」。每家一套简化线框，不用对方的真实截图和图标。
- **第一次保存**时弹「存在哪」半屏：iCloud 云盘（默认）/ 只在这台手机，文案见 PRD 屏 3。

## 3. 官网用的 iPhone Duo 稿

官网首屏要换成 iPhone Duo（10-23 发售）的展开画面。这一轮只有 390 宽的窄屏，需要另出一版。

**画面**

- 一台展开的 Duo：左边纸本世界地图，小林的路线和「此刻」标记；右边「这是你的一页」和「整理给我的 AI」的勾选预览。
- 旁边一台合上的 Duo 外屏：屏 1「最近有什么事，你想理一理？」。
- 布局参考已有画板 [WideMap.dc.html](../WideMap.dc.html)（展开后的首屏）和 [Unfold.dc.html](../Unfold.dc.html)（展开 / 合上过渡），视觉用这一轮的。

**限制**

- 网站不加载任何地图瓦片，地图只用本地世界底图，或直接导出成图片。
- 去掉演示工具栏、原型说明和所有「原型演示」字样。
- 全部是示例小林的合成内容，画面角落标「示例」。
- 设备外框用苹果官方的营销素材；没有的话画一个中性外框，不带苹果标识，也不仿画 Duo 的外观细节。
- 交付：展开、合上各一张 PNG（2 倍图，浅色、深色各一套），加一段 3 秒左右的展开动画（可选，开启减弱动效时不播）。
- 官网上标「iPhone 版 · 即将推出」，不放下载按钮。

## 4. 新增：人生录音转写导入（PRD B7）

只做一个入口，原样保存，不解析。

- 位置：「今天」里「让 AI 更认识你」的一条，和「我的 → 让 AI 更认识你」列表里。
- 标题：人生录音转写导入
- 说明：从「文件」选一份录音转写（文字稿），原样存下，以后可以交给你的 AI 整理。录音里如果有别人说的话，默认只给你自己看。
- 按钮：选一份转写 / 以后再说
- 存下后：「已存下 1 份转写」，在资料里能看到原文。
- 画三个状态：说明、存好了、文件不是文字（「这份文件读不出文字，选一份 txt 或 md 吧」）。
