# 开图 iOS「纸上生活」原型

2026-10-21，Open Design 最终导出。以 iPhone 为主要评审对象，覆盖今天、开图、资料、问问及详情、导入、设置与主要状态；桌面仅保留次要预览。

暖纸白、墨色主按钮、靛蓝交互点缀，莫兰迪柔色少量使用。足迹采用真实地图、圆点、聚合缩放和可收起的城市面板。

## 预览

在仓库根目录运行（不需要安装依赖）：

```sh
python3 -m http.server 54264 --bind 127.0.0.1 --directory docs/design/ios-paper-life-2026-10-21
```

打开 http://127.0.0.1:54264/ 。默认是 393 宽手机框；右侧目录图标可进入页面目录，切换 320、放大字、深色及失败等演示状态。地图联网加载瓦片，失败时保留本地世界几何。

## 交付与验证

- [页面和交互覆盖表](UI-COVERAGE.md)、[路由清单](ui-routes.json)
- 实际复验记录、截图和未验证项放在本轮 PR 描述中，按仓库约定不提交验收产物。

本目录是设计原型，尚未接入产品数据或原生 SwiftUI。人物、经历、健康、财务、AI 回答、导入草稿和连接状态均为演示；地点坐标为公开地理数据，住过/路过等分类为合成。实际 iPhone 的系统键盘、安全区和动态字体仍待真机验收。

产品定义继续以 [PRODUCT.md](../../PRODUCT.md) 为准。导出中的 Mac 路径、GitHub、同步与模型表单仅供布局和流程评审；iOS 实现时按平台能力和现有产品边界取舍，不直接照抄演示连接逻辑。
