快速开始#

开发者：已经在用 Claude Code、Codex 或 Cursor？不用装 App，一句话让 Agent 在你的 GitHub 上建好开图工作区，见开发者指南。

需要：Apple 芯片（arm64）的 Mac。Kaitu.app 目前只有这一个版本。

  1. 下载 Kaitu.dmg（见下载）。
  2. 打开 DMG，把 Kaitu.app 拖进「应用程序」。
  3. 在「应用程序」里双击打开。macOS 不让打开时，见下载页的说明。

第一次打开#

  • 先选资料放哪：这台电脑（不同步）、iCloud 云盘、Google Drive、坚果云，或其他同步盘的文件夹。旁边会标出这台电脑上找没找到对应的同步文件夹。选本机时默认是 ~/kaitu，空文件夹会自动建好。以后随时能换，见存放位置与同步。
  • 带来一件事：写下想改变的事，或粘贴一段和 AI 聊过的对话。点「保存并整理」时，开图先原样保存原文，再整理出「当前目标」「已知现状」「一个下一步」草稿，每项都能改。只有你点「采纳这个下一步」的那一条会变成待办，目标同时记进目标列表；其他建议留在原文里。一条都不想采纳，就点「只保存原文」。
  • AI 给出几条「可能的路径」时，先选一条，才能把它的小实验改成你的下一步。
  • 没连开图里的 AI 也能整理：在「用你常用的 AI 整理」里点「1 · 复制整理提示词」，发给豆包、Kimi、DeepSeek、ChatGPT 等任何 AI，把回答原样贴回，点「3 · 读取回答」。也可以自己填那三项。
  • 也可以「从常用的 AI 搬来记忆」（见导入与记录），或者「先随便看看」。

今天页有一份「开始使用」清单，按你的实际进度勾选：选资料放哪、带来一件事并采纳第一个下一步、让开图认识你（可选）、选你想先管的事、接入健康、日历等、选一个 AI 帮你整理、拿到第一份今天计划。点「接入健康、日历等」时，如果还没选想先管的事，会先让你选，再按选择列出要接的数据。

看资料、记原文、看地图和财务都不需要 API Key。「选一个 AI 帮你整理」不会锁定资料：开图负责保存资料，AI 负责整理和排计划，以后换 AI，资料都还在。

界面语言默认跟随系统，可以在「右上角头像 → 设置 → 界面语言」改成中文或 English。它只在这台电脑生效，也决定开图复制给 AI 的提示词和资料包用哪种语言；你写的内容和 AI 的回答不会被翻译。

App 自己的状态和问问的会话在 ~/.kaitu-app/，不在资料文件夹里。

四个入口#

入口里面有什么
今天现在最该做的一件事；你带来的规划（目标、来源和下一步）；最多三条下一步；要你核对的事；今天的日程；最近的变化和近期回顾；「随手记一句」
开图健康、足迹、资讯、方向，默认打开健康
资料日程、在做的事、健康、财务、笔记与决策、收件箱；导入、对账和详细图表也在这里
问问内置 AI 对话：会话列表、引用资料和附件、每一步读了什么做了什么

个人档案、AI 与连接、设置在右上角头像里。DSH 插件只有今天、开图、资料三个入口，没有问问页。

今天#

  • 勾选下一步就是完成；做完可以记一句实际结果，做不了就改到以后。
  • 「随手记一句」写一句就存成原文，不需要 AI；开了每日整理，会在整理时处理。
  • 待确认的日程有「确认」和「不用」。确认的、带起止时间的日程会写进系统日历，见自动任务与日历。

开图#

  • 健康：目标、本周训练与饮食、近 5 周的训练格子、健康的下一步。
  • 足迹：从家乡出发，把读书、工作、旅行过的城市连在地图上。地图图块来自 OpenFreeMap，需要联网。
  • 资讯：按你的关注方向整理的新闻。每条点「有用」或「不相关」会记下来；在「关注方向」点「让 AI 结合反馈提议」时，AI 会参考这些反馈，每日整理提方向建议时也会参考。提议的关注方向要你点「确认保存」才生效。
  • 方向：一条一行，写着为什么在意和第一步。打开一个方向，能看到目前的假设、仍然未知的事、支持和反面的依据，以及每次尝试的结果。暂停的方向仍留在列表里；归档的和点过「不感兴趣」的在「已归档」里，都可以「继续探索」，资料、尝试和变化记录都还在。

资料#

  • 财务 · 收支：转账、借入本金、偿还本金和证券卖出本金不算收入，也不算消费，单独列在「不计入收支」。转账和借款本金按带方向的金额显示，转出为负数。
  • 退款只冲减消费，不算收入，而且要和原来那笔消费对上；对不上的先进待核对，不计入。
  • 财务 · 投资：分红、手续费、税费各自单列。卖出收益有没有扣过手续费，取决于导入的成交记录。

个人档案#

  • 在右上角头像 →「个人档案」：名字和简介、事实、偏好和规则、我的目标，每条都标着出处。标为敏感的记忆不进资料包。
  • 经历：足迹里记下的读书和工作经历按时间从近到远列出。点「导出简历」得到一份 Markdown 简历，工作在前，读书在后。

资料文件夹#

全部是 Markdown、JSON 和 JSONL，任何编辑器都能打开。

版本历史#

  • 每次写入都会存一个版本。直接用编辑器改文件也行，App 开着时，改完安静 30 秒自动存版本。
  • 「设置 → 版本历史」可以恢复任一版本。恢复前会先自动保存当前版本，恢复后还能再恢复回来。
  • 「设置 → 导出全部资料」得到一个 zip，包含资料文件夹里的 Markdown、JSON 和附件，不含本机连接凭据和版本历史。

接上你的 AI#

「连接 AI」有两种：用你已经在用的 AI，不需要 API Key，靠复制资料包往返，但问问页本身不能聊；用开图里的 AI，用 API Key 或服务商的账号登录，在问问里直接聊。

用开图里的 AI（问问）#

  1. 打开「问问」→「连接 AI」→「用开图里的 AI」。
  2. 选 AI 服务：DeepSeek 默认推荐，也可以选 OpenAI、Claude、Gemini、Kimi、智谱等。粘贴 API Key，或用服务商提供的账号登录。
  3. 从服务获取模型列表选模型，或直接填模型 ID。
  4. 下一步选要不要每天自动整理（见自动任务与日历）。
  • 用 API Key 连接时，开图会发一次很短的测试请求，检查 Key、额度、网络和模型；不通过会说明原因，也不会保存这个 Key。账号登录由服务商授权。自定义服务改了 Base URL，要重新填 Key。
  • 添加过的服务都会保留。输入框下方的模型按钮会列出已保存的服务和模型，点一下就切换；要再加一个，点「添加服务商」。换服务或模型后，从下一条消息开始生效。
  • Key 只存在这台电脑的凭据存储里。
  • 可以引用文件、文件夹和其他对话；一次最多 10 个附件，每个不超过 25MB。能不能发图片取决于所选模型；提示「当前模型不支持图片」时，到「AI 与连接」点「管理模型」换一个。
  • 网络搜索默认用当前 AI 服务自带的搜索，不用另申请 Key。当前服务没有自带搜索时（例如用账号登录连接），在「AI 与连接 → 网络搜索」添加 Perplexity、Exa 或 Tavily 的 Key。
模式能做什么
只读写开图资料（默认，按钮显示「开图资料」）只能读写资料文件夹，可以搜索和打开网页，不能运行命令，读不到 Key、凭据和版本历史。每个新对话都从这个模式开始
完整 Agent能运行命令、读写这台电脑上的任何文件、上网，读到的内容会发给当前的 AI 服务。资讯、邮件或网页里的内容可能诱导它做你不想做的事，只在你信任这次任务时开启。开启要再确认一次，只对当前对话生效

用你已经在用的 AI（不要 Key）#

  1. 在「AI 与连接 → 把近况带给你常用的 AI」勾选要带的内容，点「复制资料包」，贴进 ChatGPT、豆包、Kimi、DeepSeek 等任何 AI 的对话。
  2. 聊完对它说「整理给开图」，把回答贴到「把 AI 的回答贴回来」，点「读取回答并核对」，像整理一件事一样核对、采纳。
  • 资料包里有进行中的目标、最近 30 天的结果、下一步、项目、在探索的方向和非敏感记忆。不带哪些内容、会自动去掉什么，见资料去向。
  • 在文本框里删改过资料包后再换勾选，开图会先问你：「重新生成」按勾选重做，你的删改会丢掉；「保留我的修改」则不变。
  • 这是手动接续，不算「已连接」：问问页仍要另外连接开图里的 AI 才能聊。
  • 提方向也一样：没连开图里的 AI 时，在「开图 → 方向」点「用你常用的 AI 提」，复制提示词发给任何 AI，把它的回复贴回，点「3 · 读取方向建议」。提示词带上你的目标、在做的事、在探索的方向、非敏感记忆，以及已经提过或不感兴趣的方向标题。贴回的建议标为「AI 建议 · 待采纳」，采纳还是「不感兴趣」由你定。

本机的 Claude、Codex（MCP）#

需要能运行 kaitu 命令（见命令行）。命令默认用 App 当前的资料文件夹。

  • Claude Code：在资料文件夹里打开，文件夹自带 .mcp.json。
  • Codex：codex mcp add kaitu -- kaitu mcp
  • Claude Desktop 等：添加一个 MCP 服务，命令填 kaitu mcp。

「AI 与连接 → 这台电脑上的 AI（进阶）」可以复制接手说明。

云端的 AI（同步盘接力）#

  1. 把存放位置换成 Google Drive（见存放位置与同步）。资料文件夹根目录会多出 AGENT-README.md（接手入口）和 ORGANIZER.md（夜间整理规则）。
  2. 在 Grok 等能连 Google Drive 的 AI 里说：「打开 Google Drive 的 kaitu 文件夹，先读 AGENT-README.md」。
  • 云端 AI 只新建文件（inbox/agents/ 里的记录、handoffs/ 里的交接），不改已有文件；电脑开机后，开图把记录导入。授权 Drive 时尽量只给开图文件夹。
  • 交错了怎么改：AI 可以放一份新的记录文件，第一行写 {"replaces": "之前的文件名"}，后面写改好的全部记录；只写这一行就是撤回。只能替换它自己交的文件，替换不成立时整份不生效，原文转成待整理的笔记。

导入与记录#

「开始使用 → 接入健康、日历等」按你选的事情列出要接的数据：日历、Apple 健康、账单与持仓、项目、邮件和聊天、关注方向。都可以跳过，以后再接。

  • 随手记一句：今天页，写一句就存成原文（inbox/notes/<日期>/），不需要 AI。开了每日整理，会在整理时处理。
  • 搬来 AI 记忆：「开始使用 → 从常用的 AI 搬来记忆」。复制记忆导出提示词发给你最常用的 AI，把回答贴回来。预览里不对的取消勾选，每条可以改去处：设为目标、建为在做的事、放进在探索的方向，或只记作记忆。每条都记着来源；确认后，目标出现在今天页的「你带来的规划」。
  • ChatGPT 对话：在同一页点「导入 ChatGPT 数据导出包」，选 ChatGPT 导出的 ZIP 或 conversations.json，预览后确认。对话存进 chats/，可以搜索。
  • Apple 健康：iPhone「健康」→ 右上角头像 → 导出所有健康数据，把导出的 ZIP（或解压出的 XML）在「接数据 → Apple 健康」导入；也可以直接放进 inbox/health/。每晚自动同步需要先把存放位置换成 Google Drive，安装步骤在仓库的 docs/guides/apple-health.html；自己做快捷指令见文件格式。
  • 日历订阅：「资料 → 日程 → 添加日历」，填 Google 日历、iCloud 或 Outlook 的 ICS 地址（也可以是 webcal），每 15 分钟刷新。
  • 账单：「资料 → 财务 → 导入账单」，CSV、XML、XLS、XLSX，单个不超过 36MB。按表头识别支付宝、微信、招商银行、工商银行、建设银行、中国银行、京东、美团、华西证券、海通证券、同花顺、IBKR（Flex XML）和持仓表。先预览再确认，同一份文件重复导入不会重复记账。PDF、图片和加密压缩包不能导入。
  • 邮件与聊天：「AI 与连接 → 邮件与聊天」，只读接收 Gmail、IMAP 邮箱（iCloud、QQ、163 等）、Slack 和飞书。只存来源、发件人、时间、标题、最多 280 字摘录和原文链接。
  • 项目：「接数据 → 项目」，连本机文件夹或 GitHub 仓库。
  • 命令行：kaitu import chatgpt-conversations | apple-health | ics | nut-ai <文件>，加 --dry-run 只预览。单个 .ics 文件和 Nut AI 备份用这里导入。

存放位置与同步#

第一次打开时就会问资料放哪。以后在「右上角头像 → 设置 → 换一个存放位置 → 更换」，选由谁同步：

  • 这台电脑（不同步，默认）
  • iCloud 云盘
  • Google Drive
  • 坚果云
  • 其他同步盘的文件夹

点「选择文件夹…」会填成所选位置下一个新的 kaitu 文件夹，也可以手改路径。目标必须是还不存在的文件夹，开图不会覆盖已有文件夹。点确认才会真正搬资料；旧位置会留下 WORKSPACE-MOVED.md。

不要直接把现在的开图文件夹拖进同步盘，那样会把密钥和版本库一起上传。用「换一个存放位置」迁移时，它们会留在这台电脑。

  • 云盘里只放资料文件。版本历史、Key 和凭据、搜索索引、头像、界面设置留在这台电脑。认得出的冲突副本（如「(conflicted copy)」「文件 2」）不进版本，kaitu doctor 会列出来。
  • iCloud：先在「系统设置 → Apple 账户 → iCloud」打开 iCloud 云盘；搬过去后，在访达里对 kaitu 文件夹选「始终保留下载」。云端 AI 读不到 iCloud。
  • 坚果云：默认用找到的坚果云同步文件夹。提示没找到时，先在坚果云客户端里设好一个同步文件夹，再把路径填成它里面的一个新文件夹。
  • Google Drive：云端 AI 接力用它（见云端的 AI）。

命令行：kaitu sync enable icloud|drive|nutstore [--dir <父目录>]、kaitu sync disable [--to <目录>]、kaitu sync status。同步后哪些文件进云盘、哪些 AI 能读到，见资料去向。

手机通道#

在微信、Telegram、飞书或 QQ 里给开图发消息，由问问当前连接的 AI 回答，用「只读写开图资料」模式：能读写开图资料、搜索和读网页，不能运行命令。电脑要开着、Kaitu.app 要在运行、问问要先连好 AI。只处理文字。

  1. 「右上角头像 → AI 与连接 → 在手机上和开图聊」。
  2. 按页面上的步骤连接一个通道（微信扫码登录；Telegram、QQ、飞书填机器人凭据）。
  3. 页面显示配对码，10 分钟内有效。用手机私聊机器人，发这个码。发来配对码的那个账号会成为唯一能收到回复的账号。

真机测过的是 Telegram 和微信；飞书和 QQ 还没在真机上测过。消息会经过所选平台，见资料去向。命令行：kaitu channels setup <weixin|telegram|feishu|qq>、kaitu channels pair <通道>、kaitu channels status。

自动任务与日历#

第一次在问问连上开图里的 AI 后，会问一次要不要每天自动整理。它们用你刚连接的 AI 运行；选「都不要」也能随时手动问。

任务时间默认
早间计划：排好今天的安排，等你确认07:30开
每日整理：把各个 AI 留下的交接记录合并成一份每日整理，更新各板块的下一步；最近七天没有方向建议时，只用主题词联网搜索，提 3–5 个方向建议等你采纳03:00开
资讯搜索：按你确认过的关注方向找新资料08:00关

以后在「设置 → 自动整理」分别开关、改时间（Kaitu.app 菜单「人生开图」→「设置」也能开关）。时间按「设置 → 关于」里显示的时区算。任务只在 Kaitu.app 开着时运行。

确认日程时加入系统日历#

  • macOS 的 Kaitu.app 默认打开。确认一条有起止时间的日程，或给下一步排好时间段，会写进系统的「开图」日历，提前 10 分钟提醒。待确认的建议和没有时间的待办不会写进去。
  • 加入成功的不会在今天页再列一遍；失败或只生成了日历文件时，今天页会列出这一条，可以「下载日历文件」或「重试日历操作」。
  • 第一次写入会请求自动化权限。拒绝后可以到「系统设置 → 隐私与安全性 → 自动化」允许开图控制日历，再点「重试日历操作」。
  • 关掉开关后，已经写入的事件保持不动；要清掉，点「移除开图已写入的日历事件」。
  • 浏览器里的 kaitu ui 和 DSH 插件只生成日历文件。

插件#

开图有自己的插件目录：https://kaitu.si/plugins/index.json，格式是 DeepSeek Harness 的插件市场索引。现在有两个插件：

插件包名用途
人生开图kaitu-dsh在 DeepSeek Harness 里用开图：今天、开图、资料和开图的 AI 工具。Windows、Linux 和 Intel Mac 用这个（试用支持）。
小说工作台kaitu-novel-workspace章节与资料、世界书、续写候选和科幻设定校对。

在 Kaitu.app 里装#

点右上角头像，进「设置 → 插件」，在列表里点「安装」或「移除」。装好的插件页面在 DSH 窗口里，点「打开插件页面」查看。Kaitu.app 本身就是开图，所以列表里不显示「人生开图」。

在 DeepSeek Harness 里装#

  1. 打开侧栏「插件」，点「实验性插件」旁的「更多」，打开「自定义插件市场」。
  2. 在「已安装」旁边的「发现」里点「添加索引源」，填 https://kaitu.si/plugins/index.json。
  3. 在列表里安装「人生开图」或「小说工作台」，确认框里会显示来源，核对后确认。

只装开图的话，也可以直接在「插件」里安装 kaitu-dsh，步骤见下载页。

更新#

  • 功能包：界面、资料服务、工具和技能。「设置 → 关于 → 开图功能更新」：检查更新 → 下载更新 → 重启应用。更新包要通过签名和内核版本检查，不通过就继续用当前版本。有问题可以「恢复上一版功能」；这不会恢复你的资料，资料回退用版本历史。
  • App 本身：DSH 内核（当前固定 0.2.1-rc.2）、Electron 或启动器有变化时，需要下载新的 Kaitu.app。

设置里显示「未配置更新源」时，不能在应用内检查更新，到下载页下载新版。新版 App 打开时会自动升级资料文件夹里的内置模板和技能，保留你的配置。只用命令行时，旧资料文件夹先运行 kaitu upgrade（--dry-run 预览）。

从源码运行 / 命令行#

命令行与网页版也有现成的安装包，见下载页。从源码运行需要 Node.js 22.19+（22 系列）或 24+，以及 pnpm。

git clone https://github.com/Stahl-G/rensheng-kaitu.git
cd rensheng-kaitu
pnpm install
pnpm build
node packages/cli/dist/main.js init ~/kaitu-demo --sample
node packages/cli/dist/main.js --dir ~/kaitu-demo ui

--sample 会生成合成的演示数据。工作台只监听 127.0.0.1，入口和 Kaitu.app 一样，问问在页面里连接 AI。下面的 kaitu 在源码里指 node packages/cli/dist/main.js。

命令作用
kaitu init [目录] [--sample]新建资料文件夹（默认 ~/kaitu）
kaitu ui [--port 4870] [--no-open]打开本机工作台
kaitu doctor检查资料文件夹
kaitu validate [路径]按 schema 校验
kaitu status今天、模块进度与最近 7 天数据
kaitu mcp [--http] [--port 4871] [--tools remote|all]启动 MCP 服务
kaitu upgrade [--dry-run]升级内置模板与技能
kaitu history · restore <版本> · snapshot -m <说明>版本历史
kaitu dsh [--install] [--no-automation]装进 DeepSeek Harness

通用选项 --dir <目录>，也可以设环境变量 KAITU_DIR。都不设时，用 App 当前的资料文件夹，没有就用 ~/kaitu。完整列表见 kaitu --help。

MCP over HTTP：kaitu mcp --http 只监听 127.0.0.1:4871，请求要带 kaitu mcp token 给出的 Bearer token，默认只开放读取和新增。开图不内置公网访问。

装进 DeepSeek Harness#

Windows、Linux 和 Intel Mac 用这种方式（试用支持）。装好 DSH 0.2.1-rc.2 或更新的桌面版后，在「插件」里安装 kaitu-dsh，或在插件市场添加索引源 https://kaitu.si/plugins/index.json 后安装「人生开图」，详见下载页。用命令行装时：

  1. 打开一次 DSH，在「设置 → 模型」配好模型。
  2. 运行 kaitu dsh --install。同一个资料文件夹也在 Kaitu.app 里用时，加 --no-automation，后台任务只在 Kaitu.app 里跑。
  3. 退出再打开 DSH，侧栏点「开图」：今天、开图、资料三个入口。DSH 保持自己的品牌和面板，对话用 DSH 自己的会话。

kaitu 命令来自 npm install -g rensheng-kaitu@next（见下载页）。不加 --install 会打印网页版的启动命令。

资料去向#

  • 存在这台电脑：资料文件夹，以及版本历史、Key、凭据和索引。
  • 同步到你的云盘：只在你选了云盘之后，只同步资料文件。
  • 这次发给 AI：问问把你的消息和它读到的资料发给你选的 AI 服务；完整 Agent 读到的内容都可能发出；自动任务用同一个 AI；通过 MCP 或云盘接力的外部 AI，读到的内容会发给它们背后的服务；资料包和剪贴板只发你复制的那一段。
  • 其他联网：地图图块（OpenFreeMap）、行情参考价（Yahoo，只发代码）、GitHub、日历订阅、邮箱和聊天采集。

逐项说明见资料去向。

常见问题#

一定要填 API Key 吗？#

不用。看资料、记原文、看地图和财务都不需要。想让 AI 帮忙，可以复制资料包或提示词给你常用的 AI，再把回答贴回来。

资料在哪？能直接改吗？#

在你第一次打开时选的位置，「设置 → 换一个存放位置」能看到当前位置。文件可以用任何编辑器改，App 开着时会自动存版本。

换了 AI，进度还在吗？#

在。进度存在你的资料文件夹里，不在某个 AI 里。新的 AI 读 AGENTS.md 和 OVERVIEW.md 就能接着做。

关掉 App，还会自动整理、回手机消息吗？#

不会。自动任务、手机通道、日历同步和邮件采集都在 App 运行时工作。电脑关着时，可以用 Google Drive 让云端 AI 接力。

改错了能恢复吗？#

能。「设置 → 版本历史」选一个版本恢复；恢复前会先存一个版本，恢复本身也能撤回。

有 Windows 版吗？#

有，以 DeepSeek Harness 插件的形式试用，Linux 和 Intel Mac 也一样：装好 DeepSeek Harness 桌面版，在「插件」里安装 kaitu-dsh。步骤见下载页。

怎么把资料全部带走？#

「设置 → 导出全部资料」得到一个 zip；或者直接复制资料文件夹。

和 DeepSeek Harness 是什么关系？#

Kaitu.app 基于 DeepSeek Harness（DSH）0.2.1-rc.2 打包，问问用的是它的引擎。已经在用 DSH，也可以只把开图装成插件（见装进 DeepSeek Harness）。

问问页显示「问问引擎没有载入」？#

重新安装完整的命令行与网页版安装包，再重启工作台。在那之前，仍可以在「AI 与连接」复制资料包，带到你常用的 AI。

设置里显示「未配置更新源」？#

这个版本不能在应用内检查更新，到下载页下载新版。
