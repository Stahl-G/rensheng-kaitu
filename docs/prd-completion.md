## 执行顺序和完成标准

1. 建立隔离的合成工作区，构建此分支并启动对应桌面开发实例，记录版本和加载路径。
2. 先补导入 → 提交 → 回读 → 纠错 → 再同步闭环，防重复记录、静默覆盖和删除后复活。
3. 补齐探索三层体验、地图时间和控制能力、财务适配及下钻。
4. 补齐云端独立处理、真实跨 Agent 接续、照片元数据与 Apple 能力入口。
5. 逐项运行全部 AC，并核对每项 FR 的界面、Agent 入口、失败恢复和数据导出。
6. 用 1 万条经历、5 万个元数据条目验证分页、聚合、恢复和首屏性能，保存设备与数据规模。

每个实现单元只补必要行为测试，先验证错误实现确实会失败。
修改后运行相关业务场景，再按仓库约定执行 build、typecheck、lint、test。
已通过检查仅在新改动、失败或新疑点出现时重跑。
所有 FR 实现、全部 AC 通过、桌面产物版本一致后，才把总目标标记完成。
