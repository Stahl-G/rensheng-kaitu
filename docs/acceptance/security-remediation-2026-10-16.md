## 私有记录存储与公开化语义

已同步更新 PRD §6 和 packages/core/src/agents-md.ts。JSONL 字段和记录 schema 未变化，
现有 schemas 可直接校验本机副本，无需新增格式或修改 schemas。

公开任务保留 me/data/tasks/{YYYY-MM}.jsonl。私有任务进入可信本机状态目录的
local-projects/me/data/tasks/{YYYY-MM}.jsonl；其他关联记录在该库保留模块相对路径。
本机模式的私有根为 .kaitu/local-projects，Drive / iCloud 模式不在同步目录内。
ID、原字段、全部修订与删除标记保留；私有修改的版本保存在本机库。

全部历史修订参与项目归属判断，包括 task.project、source 项目路径、结构化 references 和
方向 / 尝试父子关系；失效、循环及关联其他私有项目的记录保守留在本机。
MCP remote 检查读写入口及返回值。NOW 的 blocks、attention 分为本机与公开投影，
本机业务读取合并，公开 status、当前和过期 OVERVIEW 只用公开内容。

公开转私有逐文件写入、回读核对后才清除原件；已有本机同版本冲突以本机内容为准，完整行去重。
迁移意图保存在本机程序状态，不进版本库。中断后下一次打开自动继续，已有共享私有记录也自动迁回。
跨磁盘项目文件复制同样核对目标字节后删除原件，部分复制可继续。
计划投影先保存并核对目标，再移除旧副本，避免公开化失败丢失私有计划。

用户明确将项目改回公开时，搬回该项目全部修订和删除标记，包含私有期间新增内容；
其他仍私有、失效或循环的关联不公开。当前计划恢复相应公开投影，本机旧版本保留。
旧共享 Git 提交不重写；恢复旧版本不会将当前私有任务重新发布。
已同步的云端副本、其他设备与备份需要用户清理，本机迁移无法撤回这些副本。
自由正文里人为复制且没有结构化关联的内容不属于自动引用过滤。

界面只增加用户指定的最小提示，保留主线引导组件结构：
「这个项目的待办以后只在这台电脑上，以前同步过的副本请到云盘清理」。

## 权限设计与旧工作区兼容

scoped 文件策略排除 .kaitu、.git、本机状态根、应用 home 和真实路径别名，覆盖读取、范围读取、
字节、目录、metadata、编辑、原生 grep / glob 与开图专用工具。搜索输入和结果均检查，参数受限。
应用 home 不能配置到资料目录内；正常笔记、只读技能正文与相对资源仍可用。

完整 Agent 保留用户二次确认和 danger-full-access：它能执行命令、读写同一系统用户有权限的本机文件，
包括工作区外资料、程序状态和凭据。本次 scoped 黑名单不构成 Full 模式的系统隔离保证。
新会话默认 scoped，服务端切换、配置、关闭及工作区变更有状态转换门禁。

状态目录由本机根下 workspaces 登记决定，记录工作区 id、规范根、真实状态根和同步模式。
建立后忽略共享 config.json 的 state_dir 变化，删除或清空字段也不会降级回同步目录。
旧版正常同步工作区首次打开自动核对本机状态根、所有权及链接并建立绑定，无需 trust-state 命令；
合法的自定义同步目录同样可打开，不依赖识别标准云盘目录。换机时不可用的旧 UUID 路径映射到当前本机根。
已识别的云盘没有 state_dir 时自动分配本机状态，并迁走程序文件。
明显异常的任意外部状态路径、另一工作区所有权或链接替换会停止打开并保留原件，须先核对位置。
首次程序状态迁移完成后不再从共享目录接收新程序文件；跨磁盘复制核对字节，冲突保留原件。
财务缓存、同步位置判断和新增引导日历状态读取统一使用可信状态路径。
