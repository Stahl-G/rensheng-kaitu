# V2 页面交审

分支 `codex/ui-v2`，仅本地提交。视觉和交互依据 `docs/design/kaitu-v2-prototype.html`，没有改 PRD §6 或 schemas。

## 页面与接口

- 共享顶栏：今天、开图、资料；独立 App 另有问问。头像菜单进入个人档案、AI 与连接、设置。
- 今天：接 overview.sections、capture、completeNext、decideProposal、calendar 和现有财务视图。
  无记录显示三张开始卡；保存原文后显示“已收到”；突出一件事、最多两条下一步、三条变化。
  缺失金额显示资料不足，不跨币种相加；资料板块只在有数据时出现。
- 开图：方向接 exploration，支持在试、待采纳、暂停及原有编辑；足迹复用 MapLibre 与纠错、来源能力。
  资讯接 news、feedbackNews、tryNews；有用/不相关可撤销，更新 feed/feeds.json 的 keywords/muted；
  加到下一步生成 proposed 项。collect-news 要求第二人称点评和具体关联对象。
- 资料：六个入口接 library、项目、健康、财务、笔记正文及收件箱；详情有返回资料入口。
  健康与项目先展示原型摘要，完整记录、照片、趋势与编辑仍可进入。
- 日程：FullCalendar 标准版锁定 6.1.19，日/周/月/列表、来源颜色、虚线建议及采纳/拒绝。
  ICS 订阅 15 分钟拉取，复用 importIcs/importBatch，保留人工修改和删除，不写回外部。
  订阅地址仅存本机状态，不经页面返回或进入版本历史。
- 个人页：头像裁剪沿用原组件；事实、偏好、规则保留出处。连接页接真实模型设置、MCP 接手说明、Drive 与存放位置。
  设置接 automation、exportWorkspace、history/restore、moveWorkspace；用户改过的时间、提示词和手动删除的任务会保留。
  更换位置时重启后台进程、迁移自动任务会话；原问问记录可查看，迁移后用新对话继续。
- 问问：保留对话和 SSE，默认范围保留 74a4da4 的收紧。
  完整 Agent 二次确认后重启为 DSH 标准完整权限并续接原会话；新对话回到默认模式。

## 手动验证

1. 用临时目录运行 `kaitu init <临时目录>`，再运行 `kaitu ui --dir <临时目录> --no-open --port 0`。
   首次看欢迎三卡；记一句话，确认“已收到”，到资料 → 收件箱核对原文和来源筛选。
2. 添加自己的测试 ICS URL，切换四视图；确认建议可放进日程或不用，今天显示实际日程。
   人工修改/删除导入事件，等 15 分钟后确认不被覆盖或复活；订阅失败时已有日程仍在。
3. 在临时工作区导入合成资讯、方向和项目数据，检查三态方向、具体关联、反馈回执与撤销；
   “加到下一步”应出现在今天的待确认建议中，未确认时不当作已安排。
4. 头像 → 个人档案测试裁剪，AI 与连接核对模型/位置；设置调整时间并开关，重启后确认保留。
   导出后解包，版本历史恢复和更换存放位置只在临时 HOME 中验证。
5. 在独立 App 的临时 profile 中配置自己的模型，问问切换完整 Agent：取消应保持默认，确认后可执行合成命令；
   切回默认应收回外部文件与命令能力，新对话必须默认。DSH 插件只有三个主标签，使用宿主 AI。
