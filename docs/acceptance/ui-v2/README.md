# V2 页面交审

分支：codex/ui-v2。原型：docs/design/kaitu-v2-prototype.html。仅本地提交。

## 第一批：今天、资料与日程

- 独立 App 与 DSH 插件使用同一个 OverviewPage；今天、开图、资料同级，独立 App 另有问问。
- 今天接 overview.sections、capture、completeNext、decideProposal、calendar、四个财务视图。
  无记录显示欢迎态；原文写入后显示已收到，可在收件箱回读；下一步最多突出三项，最近变化三项。
- 资料六入口接 library 聚合与已有项目、健康、财务页面；笔记与决策可打开原文件正文。
- 日程使用 FullCalendar 标准 6.1.19，日/周/月/列表。ICS 订阅复用 importIcs/importBatch，15 分钟刷新。
  原有人工修订、删除保护沿用。日历不写回外部。地址只存在本机状态，不通过页面接口返回。
- 收件箱合并待整理与已归档原文，来源可筛选。外部渠道未连接。
  原有归档记录没有结构化去向，显示“整理去向未记录”。

## 验证

- 临时工作区浏览器：欢迎态、随手记写入与“已收到”、回读。
- 新增一个合成数据测试：ICS 拉取间隔、人工修改与删除保留、失败不清空日程。
- 本批提交前运行 build、typecheck、lint、test。

## 后续批次

方向、资讯反馈、头像个人页、自动整理设置和问问完整模式随后接入。
个人档案推测缺少现有字段，保持 PRD §6 不变，等待用户裁决。

## 手动验证

用临时工作区运行 `kaitu ui --dir <临时目录> --no-open --port 0`，不要指定个人资料目录。
首次看到三张开始卡片；记一句话后打开收件箱，核对原文。
资料 → 日程切换四个视图，添加一个自有测试 ICS URL，核对来源与刷新时间。
开图建议点击后可放进日程或不用。修改或删除已导入的测试事件后，等下次刷新核对保留。

## 第二批：方向、足迹与资讯

- 方向使用 exploration 的状态、问题、依据与尝试，卡片可直接采纳、暂停或继续；详细编辑与来源保留。
- 足迹复用 MapLibre 地图、筛选、纠错和来源能力，改为原型的通栏地图尺寸。
- 资讯接 news、feedbackNews、tryNews。反馈单独写入本机回执，并修改 feed/feeds.json 的 keywords/muted。
  撤销保留原有关注词和屏蔽项。加到下一步仍由原 tryNews 生成 proposed 项。
- collect-news 要求第二人称点评，以及具体目标、项目或方向关联。
- 修正同一日历事件被 NOW 与记录重复展示；订阅 URL 不进入版本历史。
- 临时浏览器检查方向三种状态、资讯内容与反馈入口；新增一项资讯偏好行为测试。
