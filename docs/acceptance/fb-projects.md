# projects 交审
- 现象：V2 项目卡缺 GitHub 与详情入口，进度未设置，日志带同步注释及过长提交列表，关联待办未显示。
- 原因：摘要页未复用已有仓库数据，只读 STATUS 下一步；浏览器接口直接拼接原始日志。
- 改动：卡片显示 CI、发布、Issue/PR、最近推送及绑定入口；合并关联待办，摘要去注释并限制提交标题。
- 改动：新增单项目详情、新建项目、目标确认、进度曲线、日志及来源；AI 草稿不保存，确认后沿用现有 progress。
- 改动：字数与累计提交随同步更新；其他单位手动更新。仅本机项目手动设目标，不发送给模型。
- 手动验证：临时目录初始化后运行 `kaitu ui --dir <临时工作区>`；资料→在做的事→新建项目→打开详情。
- 手动验证：提议目标，修改后确认；刷新核对数值；关联临时手稿并同步，查看进度变化及曲线。
- 手动验证：绑定 owner/repo，核对仓库数据；输入错误地址保留原绑定；卡片只显示摘要，详情保留完整日志。
- 7c 待用户确认：拟议 `projects/<slug>/view.json`，顶层 `{title?, blocks: [...]}`；不在本轮创建或读取此文件。
- 积木公共字段：`id`、`type`、`title?`；数据引用只接受本项目已存在资料的相对路径与字段，不执行表达式。
- progress：`source`（现有 progress）；显示 label/current/target/unit。curve：`source`（项目指标）、`kind`（words/commits）。
- checklist：`items[{text, checked, source?}]`；milestones：`items[{title, date?, done, source?}]`。
- links：`items[{title, url}]`（仅 HTTP/HTTPS）；note：`text`（纯文本）、`source?`。
- table：`columns[{key, title}]`、`rows[{...字符串或数值单元格}]`、`source?`；不解析单元格 HTML。
- 错误处理：整份无法解析时显示默认详情并提示修正；未知类型、缺字段、越界引用只跳过该块，其余正常显示。
- HTML 后备待用户确认：顶层 `html?` 与 blocks 二选一；隔离 iframe，空 sandbox，不允许脚本、表单、导航或同源权限。
- HTML 使用独立隔离内容与 CSP `default-src 'none'; style-src 'unsafe-inline'`，无网络、开图接口和本机文件访问。
- 检查：build、typecheck、lint 退出码 0；新增 2 个行为测试通过；全量 test 多处超时后停止，退出码 130。
- 受影响回归：项目 core 与 Remote 通过；UI 4/5 通过，外部改动存版本测试在原有 3 秒轮询上限内未出现新版本。
