## SDK 核实结论

使用已安装的 DeepSeek Harness **0.2.0-rc.2 arm64**，源应用与 `~/Developer/deepseek-harness-rc2` 均只读。

- 打包版的 Electron Node CLI 能以 `--profile sdk --patch …` 无窗口启动并完成 initialize。
  重新打包的 Kaitu.app 中也完成了 initialize、session/prompt、session.event、session.status 和 shutdown。
- 可叠加开图后端插件与技能。SDK 使用独立打包的插件入口，避免桌面插件 wrapper 的 workspaceRegistry 依赖。
  就绪门槛包含开图服务、权限、文件和沙箱服务，不能仅凭 SDK 握手掩盖插件加载失败。
- rc.2 SDK 对旧 ID 会创建新 agent；薄入口对已持久化会话调用公开 `agents.resume`，
  新会话仍调用原 HarnessSdkJsonRpcServer.prompt。已用合成模型验证进程重启后读取原有消息并继续调用工具。
- 原交审仅限制写入，仍允许读取工作区外资料和外部执行，已由下方安全修复替代。
- schedule 包虽然随应用提供，但在 sdk profile 实测未激活：缺少 sessionController。
  该服务还依赖桌面 workspace registry、默认模型等组合。保留现有隐藏 Electron 子进程只执行定时任务，
  不为省一个进程引入整套桌面依赖；问问不会聚焦或打开该子进程。

## 手动验证

1. 构建并打包，使用 desktop.md 的 KAITU_APP_HOME / KAITU_DIR 隔离启动方式，保持真实资料不变。
2. 点问问：先选已有 AI，确认接手说明可复制、页面提示需内置 AI；再连接内置 AI，由本人填写有效 Key。
3. 确认第二步默认开关，选择“都不要”或按需开启。在新对话问一个关于合成工作区的问题，检查工具详情与最终正文。
4. 新建第二个对话，切换回第一个，再退出重开并继续提问，确认上下文、列表及事件无串会话或重复。
5. 长对话向上滚动再发起新消息，确认不被拉到底部；靠近底部时新消息跟随。
   用中文输入法按 Enter 选词、Shift+Enter 换行；缩窄窗口与开启减少动态效果后再检查。
6. 在隔离工作区请求写入工作区外临时文件，确认写入失败；需提升权限的工具卡显示已跳过，且不出现审批或 DSH 窗口。
