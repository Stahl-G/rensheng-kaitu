# ask 工作区交审

现象：问问输入框出现双层聚焦框，工具像文字链接，固定问题与个人资料无关，进度分散。
原因：全局 textarea 聚焦样式覆盖局部样式；工具缺少控件外观；空状态写死示例。
改动：先更新 V2 原型，再实现单层圆角输入框、自动增高与内部滚动，保留回车、换行及输入法保护。
改动：附件改为图标按钮；模式与模型改为胶囊菜单，展示权限、当前服务和模型，支持 Escape 与移出焦点收起。
改动：工具步骤按轮次收进助手位置的进度行，可展开查看；示例问题只取已有项目、下一步和原文记录。
范围：仅原型、AskPage.tsx 和 AskPage.module.css，不改后端与数据格式，不新增依赖或测试。
缺口：现有问问后端没有取消接口，生成中继续禁用发送；停止生成需要另批后端实现。

手动验证：用临时目录执行 `kaitu init <目录>`，再执行 `kaitu ui --dir <目录> --no-open`，进入问问。
手动验证：浅色、深色及 375px 下聚焦输入框，输入多行至滚动，清空后应收回；Shift+Enter 换行，中文组字回车不发送。
手动验证：打开模式及模型菜单，检查当前权限、服务与模型；Escape 关闭；无图片能力时附件禁用。
手动验证：无资料时只显示引导；添加合成项目后重新进入问问，点击问题填入输入框；对话调用工具时展开进度查看步骤。

检查：build、typecheck、lint 均退出 0；test 退出 1，145 通过、30 失败，主要为 15 秒超时，另有 iCloud、凭据日志解析及版本监听断言失败。
