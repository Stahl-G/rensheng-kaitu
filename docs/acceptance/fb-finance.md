# finance：无账户直接导入账单

- 现象：没有财务账户时，导入面板要求回到对话建账户，无法选文件。
- 原因：文件选择依赖账户，提交接口也只接受已有账户。
- 改动：先选文件，复用解析器识别支付宝、微信、券商等来源，预览给出账户名。
- 预览可改名（点「更新预览」）或改选已有账户，账户切换后重算预览。
- 确认时账户与账单整批校验、一起写入并保存一个版本；放弃和错误文件不建账户。
- 重复导入复用识别到的唯一同源账户，继续使用现有账单去重规则。
- 只新增导入接口参数，沿用现有账户记录；没有改 schemas 或持久化格式，没有新增依赖。
- 自动检查：新增 2 项行为测试通过，覆盖首次导入、改名、放弃、错误文件、已有账户与重复导入。
- 临时工作区接口实跑：无账户预览和放弃后仍无账户；微信改名确认新增 1 条；回读账户名正确；重传跳过 1 条。

- 最终检查：build、typecheck、lint 退出码均为 0；全量测试多个既有模块失败后连续两分钟无输出，中止运行，退出码 130。

手动验证：
1. 用临时 HOME 创建空工作区，运行 `kaitu ui --dir <临时工作区> --no-open`，进入「资料 → 财务 → 导入账单」。
2. 选择支付宝、微信或持仓样例，修改账户名并更新预览；先放弃，确认账户列表为空，再重新上传确认并回读。
3. 再传同一文件，确认不新增账单；在预览切换已有账户，检查新增与已存在计数随账户更新。
4. 在浅色、深色和 375 像素宽下检查账户选择、改名、预览与确认按钮。
