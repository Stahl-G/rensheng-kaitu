# 品牌换色：深青 → 朱砂 · 2026-10-16

用户反馈：主色调接近许多 AI 应用常用的绿色和青色，看久了容易审美疲劳。只改颜色，布局和交互不变。

## 为什么是朱砂

- AI 应用大多用冷色（青、蓝、紫、黑），暖红一眼能区分开来。今天上午换掉的亮蓝和旧紫色也不再考虑。
- 「开图」配朱砂：像地图上的红色路线，也像中文里的朱印，正好对应「从全貌走到下一步」。
- 界面里没有红色状态色（报错用琥珀底），品牌红不会和报错混淆。为此把右上角的状态文字改成中性色，状态好坏只看圆点。
- 刻意做得比 Claude 的珊瑚色更红、更深，避免混淆。

## 改了哪些颜色

| 用途 | 浅色（旧 → 新） | 深色（旧 → 新） |
|---|---|---|
| 主按钮 `--primary` | #2E7F86 → #B23A2A | #4C9AA0 → #E98571（按钮文字 #2B0D08） |
| 链接 `--link` | #1F6F78 → #A33325 | #8FCAC6 → #F2A493 |
| 问问底色 `--ask` / 边线 | #EDF4F3 / #CEDFDD → #F9EEEB / #ECD3CC | #202E2F / #3A5353 → #33221F / #5A3A33 |
| 开图与地图 `--explore` | #0F4C5C → #7C2A1E（浅底 #F6E8E4） | #6FB3B4 → #E0907F（浅底 #3C2420，文字 #F2B4A6） |
| 标志三折（深 / 中 / 浅） | #0F4C5C / #2E7F86 / #9FD3CF → #7C2A1E / #B23A2A / #F0C2B5 | #2B6E7E / #4C9AA0 / #B5E0DC → #A8402F / #D9694F / #F7D0C5 |
| 桌面图标底块 | #F4F7F7 → #F7F2EF | — |

DSH 插件的 `--kt-*` 变量同步更换。其余板块（健康、在做的事、资讯、财务、关于我）和地图底色不变。
设计稿同步：[色板页](../../design/palette.html)（旧色为深青、新色为朱砂）、[V2 原型](../../design/kaitu-v2-prototype.html)、`kaitu-mark.svg` 和各 `.dc.html`。
原型深色块的媒体查询之前写坏了（`prefers-color-scheme` 被插入的一行拆开），这次一并修好，原型的深色模式才能生效。
