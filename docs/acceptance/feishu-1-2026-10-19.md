## 原有接入边界

依据官方 `larksuite/cli` 1.0.98 源码 `017b19a793ad71794a02887ede04757f3d82e10d`。
npm 二进制一致性、真实账号/认证、个人资格、十月额度、云端与移动 UI 未实测。
folder 仅为开图 allowlist，不是 OAuth 硬隔离。凭据由用户的官方 CLI 在本机管理，无开图服务器上传。
请求数是外部 CLI 只读调用数，不是上游 HTTP 数；fetch 的内部 HTTP 调度、额度不由本原型控制。
正文之外的附件、评论、资源引用不保证保真，不下载外部资源或执行原文。
硬链接不受支持时显式失败。进程被强杀可能留下导入锁，须核对无运行中的导入再手动清理。
未做飞书聊天接收、安装器、部署、合并或第二 PR。PR31 的新增范围说明由外层更新。
