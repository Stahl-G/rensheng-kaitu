# 正式设计验收七项更新

本轮取代先前浅色白线加描边方案。浅色路线及空心城市点用墨蓝 #263f64，深色用白色；没有浅色白线底层。来路只按实际可画出的、日期明确且不重叠的居住顺序分配透明度，最早 0.35、最新 0.9；只有一条时用 0.9。未知日期不连线。

“我”使用 18px 实心圆与淡光晕，其他城市保留小空心点。A 路线尾迹只是用户倾向，仍未定稿；新版 B 为带方向缺口双环，C 为竖起三折地图坐标，见 docs/design/footprint-marker-options。预览中的北京、上海、东京为合成方向示意，不代表实时位置。

深色本地陆地改为暖棕墨 #554d43，水为低饱和深靛蓝 #1c293c；陆地地形明暗系数从 .34 降为 .12，水从 .12 降为 .06。联网 hillshade 深色强度也降为 .12。原 Natural Earth 来源及 SHA256 未变，浅深本地瓦片合计 **11,087,538 字节**，仍低于15MB。

来路常显起点与“我”的城市名；其他点可悬停或点击查看名字和已知年份，不明年份显示“时间未知”。`labels.json` 为真实鼠标事件收据：悬停及点击均显示“柏林 · 2008 · 2011”，同时有“起点 · 天府”和“我 · Shanghai”。年份单次线性归集，不为每个点重复展开全部经历。左上状态句与数字在浅色有淡纸底，深色有暖墨底。

## 真实透明度与回归

`alpha-routes.png` 与 `alpha-basemap.png` 通过真实 UI 的“经历连线”开关采集，视口、镜头及底图不变。按真实城市坐标投影对比 RGB，前三段观测透明度中位数 **0.350、0.489、0.625**，与绘制值 .35/.4875/.625 一致；第四段可见像素最大约 .764。透明度确实进入 MapLibre paint，而非只写进字段。`rendered-alpha.json` 保留原始估计：最后一小段与城市圆环/“我”的光晕重叠，不能从该截图独立精确估计0.9；不把混合像素当成精确测量。

完整插件构建（含客户端类型检查）、完整 lint、足迹状态/现居/证据共8项检查通过。新测试覆盖乱序输入按真实时间得到首末 .35/.9 及未知日期不插入。原锚点、CSP、订阅镜头及列表修复保持。

大样本300城/2000经历的重复打开：地图出现观测上界211.8ms，lifeMap HTTP30.4/22.3ms，三态按钮反馈最慢21.5ms，异常/CSP违规0，原始收据在 ../product/design-large-startup.json。不是冷服务启动计时，也不是性能全面改善的结论。此前整体 CLI 冷启动约1.73秒、Electron原生窗口未验的边界继续保留。最新提交CI以固定head检查为准，未合并或发布。
