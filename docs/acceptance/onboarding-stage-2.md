# 新手引导阶段 2 交审

基线：`main 113e88a`。阶段 1 已合并，本轮接共享界面与当前数据入口。

## 实现

- 独立版与 DSH 复用欢迎页、四步引导和今天页「开始使用」清单。支持上一步、逐步跳过、逐项跳过、重新开始。
- AI、提示词、起步选项、所需数据源读取 core 内容；粘贴解析、去重、确认和完成状态都走阶段 1 接口。
- 复制调用 clipboard；失败时选中提示词。预览按服务端类别分组，可取消勾选，确认整批写入。
- 日历直接打开 ICS 订阅表单；财务打开已有导入面板；健康与 ChatGPT 文件走已有导入预览；项目文件夹/GitHub、关注方向走预览与确认。
- 邮件和聊天打开「AI 与连接」的渠道设置。问问打开连接设置，已有 AI 打开「AI 与连接」，先不用直接完成。DSH 只显示后两项。
- 引导中打开已有页面后可返回原步骤。重新开始时旧请求不能推进新一轮引导。
- 同步更新 core 的日历订阅、已收取邮件聊天和未下载 iCloud 文件的判定；补齐项目 GitHub 预览与确认，复用现有绑定接口。
- 修复基线 `overview-service.ts` 重复导入 `KaituError` / `Workspace` 导致的构建失败。

未改 PRD §6、schemas 或测试文件，没有新增测试。

## 接口接线

共享页面通过 `OnboardingServices` 调用以下方法。独立版转到 `/api/product/<method>`；DSH 转到同名 Remote。

| 页面操作 | 方法 |
| --- | --- |
| 加载内容、选择、是否显示和实时清单 | `onboarding` |
| 记录已看过、事情、跳过项与 AI 选择 | `onboardingChoose` |
| 粘贴预览 / 确认 | `onboardingMemoryPreview` / `onboardingMemoryConfirm` |
| 健康或 ChatGPT 文件预览 / 确认 | `onboardingImportPreview` / `onboardingImportConfirm` |
| 项目、关注方向预览 / 确认 | `onboardingSetupPreview` / `onboardingSetupConfirm` |
| 取消预览 | `onboardingCancel` |

项目输入在现有 `OnboardingSetupInput` 上增加可选的 `github`（仓库地址或 `owner/repo`），不增加工作区字段。
GitHub 同步失败返回 `github.ok=false`，保留项目和预览供重试；不会覆盖同名但绑定不同仓库的项目。

## 实际验证

2026-10-16，使用 `kaitu ui` 的 `startUi` 服务和构建后的独立页面，在全新的临时工作区运行。
本机引导状态、采集状态和全部样例文件都放临时目录，没有访问真实工作区或 `~/.kaitu-app`，没有填写真实凭据。

- 首次打开出现欢迎页；四步走完后显示今天清单。
- 粘贴 5 行合成记忆（含重复、列表前缀、日期、无格式行）得到 4 个候选；取消一个候选后确认，个人档案显示 3 条。
- 选择项目、健康、财务、日程和资讯后，只显示服务端返回的相关数据源。
- 日历打开已展开的 ICS 订阅表单；返回引导保留当前步骤。
- 合成本机项目先预览再确认，随后显示「已接上」。关注关键词同样先预览再保存。
- 合成 Apple 健康 XML 预览新增 1 条，确认后显示「已接上」。
- 财务打开已有导入面板；空账户时展示现有「先建账户」入口。邮件聊天跳到渠道设置，未填写账号。
- 跳过未准备的数据源、选择先不用 AI，今天清单显示 4/9；已跳过项仍可「去做」。
- 只选资讯时数据源只剩关注方向。已有 AI 跳到「AI 与连接」；问问和清单的 AI 按钮打开已选中内置 AI 的 API Key 设置，未填写凭据。
- 刷新已有数据工作区没有弹欢迎页；「重新走一遍」、上一步和跳过可用；复制提示词显示「已复制」。
- 清除临时本机引导选择后，已有数据工作区仍返回 `showGuide=false`。
- 临时构建无 `renderAsk` 的共享页面分支，预置 `aiChoice=builtin` 后走完整流程：顶部无问问，第 4 步仅有已有 AI/先不用，默认正确归一为已有 AI。
- 检查桌面浅色及 390px 深色布局：步骤换行、选项单列、清单按钮可用，无横向溢出。

## 验证边界与复验
