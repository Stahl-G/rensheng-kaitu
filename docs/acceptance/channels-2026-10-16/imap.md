# IMAP 交审

实现：OpenClaw IMAP 的配置、发件人认证门、游标/Message-ID 去重/有限重试、IDLE、分批拉取与重连退避，
适配为独立只读采集器。共用本机账号锁、600 权限配置与状态、确定性 `.note.md` 投递、状态/添加/测试/断开接口。
Kaitu.app 的 local.mjs 启动 startUi 后自动启动采集器，退出时等待停止；DSH 与 startInboxLoop 一起启动并在销毁时停止。
最小设置入口位于 AI 与连接，供 ui-v2 接替。未改 PRD §6 或 schemas。

来源：只读 OpenClaw 副本，包版本 2026.10.4，适配 `extensions/imap/src/config.ts`、`sender-gate.ts`、`state.ts`、`watcher.ts`。
各文件保留 Adapted from 文件头，MIT 全文见根目录 THIRD_PARTY_NOTICES.md。未复制插件 SDK、prompt 或 Agent 派发。
本地函数替代字符串过滤、认证强度比较、常量时间比较、状态存储、调度与健康报告。

与上游的必要差异：不要求发件人白名单，未验证邮件可作为不可信资料接收；没有可信 authserv 或地址 token 绕过。
不保存完整正文和附件；大于 1 MiB 的源邮件跳过，避免截断后错误认证。原文链接为 Message-ID URI 或 IMAP UID URI。
首次连接和 UIDVALIDITY 改变只建立当前位置，不采集历史。Outlook 支持手填 OAuth2 token，未实现 OAuth 登录/续期。
不做结构化任务提取、模型调用、发消息或修改邮件状态。钉钉不在本轮范围。

验证：一个假的 IMAP 传输行为测试覆盖新邮件投递、归档后重复不重写、凭据不进工作区、600 权限、同账号单运行者及重启。
测试仅使用临时工作区、临时本机状态和合成邮件，mailauth 也使用假的认证器，不联网。
真实邮箱、真实 Drive 多机同步和原生桌面连接未验证；Drive 两端使用相同确定性文件名，不是分布式事务保证。
构建、类型检查、lint 通过；全量测试默认并发时探索模块原有用例触发 15 秒超时，
用 `pnpm test --maxWorkers=1` 降低并发重跑，保留原有时限和断言，47 个测试文件、132 项测试全部通过。桌面主进程按现有 esbuild 配置打包后可加载。

手动验证：用隔离工作区和测试邮箱启动开图，添加并测试账号；连接后从另一个邮箱发一封邮件。
在「记录」回读摘录，核对原邮箱仍未读；关闭再打开，核对不会重复。断开后确认不再采集且本机凭据已删除。
同时打开 App 与 DSH，核对同账号只有一个连接。不要使用真实私人资料做自动验收。
