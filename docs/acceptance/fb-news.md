# 资讯图片与关注方向（第 4、9 条）
- 卡片用 NewsImage 显示 `item.image`，失败回落色块；独立 App 的 CSP 已允许 https 图片。
- 「采集规则」展开「关注方向」：可手写增删改，或让问问已连接的模型另开会话生成 5–10 条草稿；先显示新增 / 移除，确认后才写入。
- 只写 `feed/feeds.json` 现有的 `keywords`，不改数据规范。「有用 / 不相关」不再暗改关键词和屏蔽来源，只在生成下一版时参考。
- collect-news 技能、定时任务和 Grok 指令按已确认的关键词采集。
- 手动验证：`kaitu ui --dir <临时工作区>` → 开图 → 资讯，看有图、无图、坏图卡片；打开采集规则，改词看差异，确认后重开核对。
