## 实现结果

- 默认仅总览、开图、记录。个人档案、连接和高级设置移至右上角，原有模块能力收进详情。
- 首页全局选三项下一步，按逾期、优先级、截止日和确认状态排序；其余折叠。最近变化默认三项，回顾只留一个入口。
- 日程建议可以直接确认或不采用，确认后从待处理区消失，写入现有版本历史。
- 原文记录不要求模型，保存到既有笔记收件箱，可在全部资料回读；显示“已收到，等待整理”。
- 健康与财务先显示摘要，无数据不铺空图表。新用户没有预设睡眠、训练、蛋白质与热量缺口目标，旧用户配置保留。
- 足迹、方向、发现分开。地图筛选收进二级工具，X 热门收拢。方向沿用真实目标，完整实验对象仍在后续范围。
- `Kaitu.app` 默认启动独立本地资料服务与共享 React 页面，只有主动选择内置 AI 才启动 DSH。
- 原有 DSH 插件使用同一套页面；默认不自动创建多种定时任务，模型 Key 提示不阻塞资料查看。
- `PRODUCT.md` 成为当前界面唯一依据，旧 PRD 明确为历史设计，原数据规范保持。

## 本轮发现与修复

1. JSON 序列化把未填写的财务选项传成 `null`，导致财务接口报错。现在在传输边界归一化为空选项。
2. 初版独立桌面 bootstrap 顶层等待 `app.whenReady()`，阻塞 Electron 就绪，进程存在但没有本地监听。
   改为启动异步入口后返回，重新打包后服务及读取正常。
3. 初版草稿会被其他标签页提前领取；修正为带 ID 的目标窗口接续。
4. 首次会话恢复还可能打断新会话导航。现在打开函数返回实际是否完成，草稿只在成功打开后确认领取，失败留待重试。
   原始空白草稿结果未计通过；修复后的界面显示完整内容。
