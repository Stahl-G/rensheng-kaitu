## 实现与业务结果

- 足迹详情可以直接打开现有来源的文字原文，支持工作区 Markdown、JSON、JSONL、TXT，以及网页入口。
  支持 `#L20`、`:20`、`:L20` 行定位，显示附近片段并突出定位行；来源移动或定位失效有明确结果。
- 原文入口只接受已有经历 ID，不能指定任意路径；工作区外、隐藏目录和指向程序状态的链接被拒绝。
  大文件按需分块扫描到目标行，展示内容最多 256 KiB，不把整个对话文件装进页面。
- 年份包含持续经历的中间年份，新增日期区间和清除入口。筛选收起后仍显示当前条件。
  年份、月份、闰年及未知精度按同一套逻辑处理，筛选不会改写原始记录。
- 地图与列表共用时间和事实判定。有未来结束日期的当前工作可以归入“现在的生活”；未来到访与推测留在待核对区。
- 地图的待核对经历计入总览状态，并提供直达足迹的处理入口。
- 外部写入后，独立资料页通过文件事件自动回读地图；DSH 插件在可见窗口每五秒回读。
- 窄屏底图失败时自动回退列表，来源、纠错和隐藏入口仍可使用。

## 发现、修复与检查

1. 原年份列表只列起始年，持续经历的中间年份缺入口。现在按实际时间区间生成。
2. 过去只按起始年份筛选。现在按闭区间重叠处理，开放结束的生活/工作经历保留持续区间，未知日期独立。
3. 原文初版只加载文件前部，远处行号无法定位。改为异步分块扫描，四万行资料的第 30000 行能定位到独有证据。
4. 地图原来只在挂载和本页操作后读取，外部 Agent 的新记录不会出现在已打开页面。已补自动回读。
5. 窄屏故障验收发现：列表原来被默认地图视图隐藏。[原始失败界面](run-03/offline-before.jpg)保留，修复后自动切换列表。
6. 日期精度覆盖遗留字段：标为年份的完整日期按整年投影，避免把不确定的月日当成已知事实。
