# 界面设计输入（给 Claude Design 重做 DSH 里的开图 App 用）

状态：收集中。后端完成后据此重新设计，实现为 DSH App 插件页面。

## 首屏与导航

- 第一屏是「今天」，不是对话。导航只有 4 项：今天、健康、动态、我的；设置在侧栏底部。
- 人只看需要人看的内容（PRD P3）：进度、待确认、下一步。

## 导航命名（待定，用户反馈：现在的名字太抽象）

- 原则：按「点进去能做什么、看到什么」起名，不按数据分类起名；每项下面一行实时小字（如「3 件待确认 · 下一件 18:00 腿部训练」）。
- 候选：今天 → 今天做什么 / 今天安排；健康 → 练·吃·睡 / 身体数据；动态 → 每日资讯 / 我关注的新鲜事；我的 → 我的目标 / 关于我；项目 → 在做的事 / 项目进度。
- 定名方法：设计时出 2–3 套，找真实小白做 5 秒测试（只看导航 5 秒，问「想记今天吃了什么会点哪个」），选点对率高的。
- 显示名来自各模块 `module.json` 的 `name`，目录名不变；设置 → 模块管理里用户可以改名（PRD §7.6）。
- 「项目」是放进导航还是并入「我的」，设计时一起定。

## Agent 对话

- **底部常驻输入条**，每页都有：占位文字「跟开图说点什么…」，上方 2–3 个随页面变化的建议按钮（今天：「我今天该做什么」「记录早餐」；健康：「记录训练」「这周睡得怎么样」；新用户：「导入我的 ChatGPT 记忆」）。
- 发送或点开后，**右侧滑出对话抽屉**，当前页面留在左边并实时刷新（说「深蹲 3×12 60kg」，左边图表立刻多一个点）。DSH 里用 `ctx.sidebarRight` 承载对话插件。
- Agent 回复带**操作卡片**：「已记录训练 · 撤销」「建议 18:00 腿部训练 · 确认 / 不要」，与工作台确认逻辑同源。
- Agent 主动提醒（早间计划、待确认日程）进「今天 · 需要你处理」，不往对话里推消息。
- 首次使用：抽屉自动展开，由 Agent 带着完成上手三步（导入 ChatGPT 记忆 → 填目标 → 说「早上好」），完成后收起。
- 手机（微信 / 飞书 / QQ / Telegram）与电脑是同一个会话。

## 其他已知要求

- 健康页脚固定「只做记录与趋势，不构成医疗建议」。
- 体态照片墙 + 两个日期并排对比。
- 设置：导入（预览 → 确认 → 撤销）、版本历史、模块、同步到 Google Drive、手机连接（扫码）、隐私说明。
- 界面里不出现 git 字样，用「版本」「历史」「恢复」。
