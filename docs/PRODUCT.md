# 开图：当前产品定义

更新：2026-10-16。此文件是当前界面、首次使用和功能优先级的唯一产品依据。
历史 PRD 中的能力继续保留，但不再决定导航与默认布局。

## 产品目标

让 AI 持续了解你，把想改变的事变成能推进、能查回的个人进度。让人看见现状、记录变化、探索下一步。
开图承担整理与系统复杂性，用户无需理解模块、MCP、DSH 或数据格式。
数据、来源、ID 与现有追加修订规范继续使用，不因入口精简删除已有能力。

## 默认入口

| 入口 | 默认内容 | 按需进入 |
|---|---|---|
| 今天 / 我的现状 | 最重要的一件事、最多三条跨模块下一步、必要确认、已有数据摘要、最近三项变化、原文记录 | 全部下一步、日程、完整变化、近期回顾 |
| 开图 / 人生探索 | 轻量方向卡片、依据、未知与下一次尝试 | 足迹地图、城市经历、发现与资讯、地图筛选工具 |
| 资料 / 全部资料 | 项目、健康、财务、知识与决策、记忆和原文记录 | 各模块详情、导入、对账与高级图表 |
| 问问（独立 Kaitu.app） | 原生内置 AI 对话、会话列表与工具详情 | 首次 AI 连接与自动任务设置 |

独立 Kaitu.app 使用四个同级标签：今天、开图、资料、问问；不另设顶栏问问按钮。
界面以 [V2 可点击原型](design/kaitu-v2-prototype.html) 为视觉与交互依据，示例数字全部换成真实接口或空状态。DSH 插件使用今天、开图、资料三个入口与 DSH 原生会话。

个人档案、AI 与连接、高级设置放在右上角。项目与健康等高频摘要可固定到总览。
财务与地理足迹都是可选能力，不要求新用户第一天设置。

## 默认行为

问问默认模式只读写开图资料，可以搜索和打开网页；不能运行命令。搜索按本机 Key 选择服务，优先 DeepSeek，其次为用户添加的 Perplexity 或 Exa。网页读取只访问经校验的公网 HTTP/HTTPS。

- 首页全局最多突出三项下一步。按逾期、优先级、截止日和已确认程度排序，不设模块配额。
- 最近变化默认三项；日报、周报、月报收拢为一份近期回顾入口。
- 无记录时不铺空图表，不把未知显示为零。健康先摘要，财务先关键指标，详细分类按需展开。
- 新工作区不预填训练频率、睡眠作息、蛋白质或热量缺口等个人目标。既有用户规则保留。
- 查看资料和保存原文不要求模型或 API Key。用户主动选择内置 AI 后才配置模型。
- 内置问问：填一个 AI 服务的 API Key（DeepSeek、OpenAI、Claude、Gemini、Kimi、智谱等都可以）。DeepSeek 默认并推荐，模型可在「AI 与连接」切换，下一条消息生效。
- 连接前以最小请求验证 Key、额度、网络与模型，失败保留可操作的原因。Key 只进入本机凭据存储，配置和接口返回只含凭据引用与连接状态。
- 图片上传依所选提供方和模型能力开放，不支持时按钮置灰并解释原因。
- Kaitu.app 第一次打开内置 AI 时询问一次每日整理与早间计划，默认开启；资讯搜索默认关闭。设置可随时开关。已有任务保留用户的时间和内容，不重复创建。
- 默认把用户确认且有明确起止时间的日程加入系统「开图」日历；浏览器、DSH 或授权失败时生成日历文件，设置可关闭。
- 资讯默认属于“开图 → 资讯”；X 热门、讨论与来源细节收拢。
- 足迹先展示经历；图层、年份、列表切换收进二级工具，不与方向探索混成同一个坐标图。
- 方向先记下问题，动机、假设、未知条件和关联资料按需补充。AI 建议由用户采纳后进入探索。
- 尝试记录投入、期限、观察标准和实际结果；完成行动不自动证明假设。依据保留当时针对的问题。
- 暂停、归档和调整假设保留资料、结果与变化轨迹，不生成成功概率或复杂节点图。
- 用简短状态区分“已收到、已更新、需要核对”。原文保存不冒充结构化数据已更新。

## 首次使用

首批用户包括已有 AI 计划的人，以及用过 chatbot、尚未用它管理生活的人。
欢迎页约三分钟，默认「说出想改变的一件事」，也可并列选择搬来 AI 记忆。
先保存原文，再核对当前目标、已知现状和一个下一步；只采纳用户确认的这一条。
已连 AI 且不知道该做什么时，先给 2–3 条可能路径，说明理由、未知和低成本小实验，由用户选一条再核对下一步。
没有模型时手工填写，不显示路径卡片；原文保存不依赖 AI。

今天页在开始使用清单上方展示刚采纳的下一步、目标和原文依据，可完成并记结果或改到以后。六项清单按数据实时计算：带来一件事并采纳、认识你（可选）、选事情、接数据、选 AI、第一份今天计划。选事情、接数据、选 AI 均为独立可选面板。

## 本轮优先级与验收

1. P0：三入口、首页三项重点、首次原文记录、旧入口收拢。无模型用户能记录并在全部资料中读回。
2. P1：摘要优先、无误导性默认数值、同步状态、已有 AI 接入与内置 AI 选择、独立浏览。
3. P2：足迹体验与轻量方向、云端请求进入正式结构化记录并刷新视图。

每批用 Computer Use 验证真实行为，保存输入、结果与版本。底层回归只补防真实错误的测试。
三至五名新用户的十分钟任务观察作为独立体验验收：记录一次、找到项目或健康数据、理解下一步。
真人体验不能由 Agent 自评代替。
