# 任务：开图总览页对齐最终设计

第一版已在 dsh 桌面应用实测加载成功（`packages/dsh-plugin/src/client/`）。现在要按**最终设计稿**对齐。设计稿是 `docs/design/overview.dc.html`（有数据）和 `docs/design/overview-empty.dc.html`（空状态），以它们为准；它们在你上次开工后更新过，一定要重新读。不联网、不提交、不加依赖。

## 要改
1. **顶部板块栏**：今天 · 健康 · 在做的事 · 资讯 · 关于我。每个板块名前有它的颜色圆点，鼠标停留显示一句说明（文案见设计稿 `tip`）。右侧有收起按钮，收起后只剩一个小按钮「<当前板块> · 展开板块」。收起状态用 localStorage 记住。现在只有「今天」有内容；点其他板块显示一句「这一页还在做」，加上一个回到「今天」的链接。
2. **页面文案**：大标题改为「今天」，原来的「今天」小节改叫「日程」；按钮「问 Agent」改为「问问开图」。
3. **板块配色**（在 CSS Module 的 `--kt-*` 变量里定义，并给深色值）：今天/总览用墨黑 `#1F1E1D`，健康用绿 `#2E8B57`，在做的事用紫 `#6B5BD6`，资讯用琥珀 `#C47A12`，关于我用玫红 `#C2507A`。「下一步」每条的模块标签按所属板块着色：浅色底配深色字，加一个小圆点。
4. **健康卡片改成图表**，照设计稿：训练是一周 7 个方块，练过的那天填绿；睡眠是 7 根柱子，加一条目标线，没记录的那晚画虚线框，不画成 0；蛋白质是一根进度条，目标区间加深显示，估算值用斜纹；体重没有数据时显示虚线框，里面放「记一次」按钮。这些数据需要的按天明细，加进 core 的总览数据里，复用现有记录读取函数。统计区间只在卡片标题旁写一次，不要每项重复。
5. **项目卡片**：右下角是近 7 天按天的产出小柱图，每天一个固定高度的浅紫槽，有产出的部分从底部填紫色。
6. **近期变化**：每行前面加来源头像（本机 Agent、云端 Agent 的名字首字母、你）。只显示对用户有意义的改动，隐藏系统维护类版本，比如「开图升级到」「重新生成了 AGENTS.md」「文件夹有改动」这类。来源无法识别时不要显示「未来源记录」，留空即可。
7. **「需要你处理」**：三项都为 0 时整栏不显示；为 0 的单项也不显示。
8. **左侧栏的品牌**：dsh 侧栏标题和设置都归 dsh 管。查一下 rc.2 是否支持插件或 profile 改应用名和品牌标识，在汇报里写结论和依据，**本次不实现**。
