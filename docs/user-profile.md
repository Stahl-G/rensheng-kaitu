# Agent 阅读画像

`USER.md` 是可删除、可重建的只读画像，JSONL 和记忆文件仍是正本。它只包含交接包中的目标、结果、下一步、项目、方向、非敏感且未归档的记忆，以及用户确认的当前阶段；不含财务。每行附原文件与记录 ID，生成头记录时间、发布端标识和来源指纹。正文约 1k token 的预算按 3000 UTF-8 字节控制，整行保留，更多资料读正本。

在一台指定的电脑上执行：

```sh
kaitu profile-publisher enable --dir <资料目录>
```

默认不自动指定任何电脑。建议指定每天整理的电脑；指定状态保存在既有本机状态目录的 `user-profile.json`，不进入同步、历史或备份。其他电脑正常写正本，既有后台刷新和保存版本流程会让发布端刷新画像。仅使用文件的 Agent 要留意生成时间；App 不运行时可手动执行 `kaitu profile-publisher refresh`。

换电脑时，先在原电脑 `profile-publisher disable`，等云盘同步完成，再在新电脑 `enable`。已有画像属于另一发布端时拒绝覆盖；未生成画像的设备也不会自行竞争发布权。云盘不提供跨设备原子锁，因此不要同时在两台尚未同步的电脑上指定发布端。

来源缺失、未下载或有同步冲突时撤下旧正文，只保留占位，来源恢复后自动重建。画像自身卸载不阻断正本写入、修改、删除、恢复或升级；画像不进版本历史、GitHub 备份、下载检查或格式校验。Agent 不能通过普通写工具修改画像，改动仍提议到 `inbox/agents/`。


## 按需查找（读取端 v1）

USER 的领域入口与既有 `phone/library.json` 的可选 `navigation` 扩展由 `userNavigation` 同源生成。沿用 JSON Schema 的开放对象扩展与现有 `path/title` 命名；没有新增业务记录字段。扩展 `version: 1` 是能力握手，旧手机忽略，缺失或未知版本的手机保留原读工具。机器视图包括 `status`、`modules`（`path/title`）及 `files`（`path/title/updated_at`）；更新时间仅是来源修改时间，不是事实日期。路径复用已有源位置，无稳定 ID 的外部改名在下一次生成中删除旧入口、增加新入口。

这一片只索引 NOW、me 的档案/规则/目标/状态，以及项目、学习、决定的一层 STATUS/log/notes 原文。无摘要仍以标题或路径进入目录。目录不覆盖全文、附件、所有收件箱或记录；没有命中不能解释为没有资料。财务模块（含别名）在标题和数量生成之前按既有 handover 权限排除；记忆与纠正关系不复制到机器目录，仍走现有完整记忆折叠和受控读取。人看的 `items` 不进入 Ask。

文件保存与同步后沿用快照 watcher 的合并更新和每分钟对账；解析复用文件状态缓存。生成在同步函数内完成，没有异步模型摘要可晚到覆盖新正文。库快照原子替换；失败保留上次文件，来源占位时保留上次目录并标 unavailable，手机不使用其命中。App 未运行时不会承诺继续更新。USER 各节分别预留预算，避免长待办挤掉身份信息。

iOS 在准备时从本机缓存加载这份导航，仅注入范围、截至时间与检索方法；标题和片段必须回读当前允许的原文。每轮准备不再发现全树模块，读取具体文件时核对其模块身份；record_list 仍在需要时完整跨月折叠 id/rev/tombstone，未使用查询月份剪枝。搜索是标题/路径检索，分页原文仅约束模型输出；当前 store 仍可能完整下载一个命中文件，不能宣称减少了它的下载字节。

外部通用 Drive 文件读取不继承 Kaitu 的运行时权限。USER 是既有不含财务的公开交接投影；机器导航只导出上述非财务来源，不导出敏感记忆。给外部 Agent 的 AGENTS 说明指向同一入口，但不承诺所有 chatbot 都遵循。未来 MCP 可映射导航、搜索、证据三项读取能力；本轮不注册工具、不更新 npm。
