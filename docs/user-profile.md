# Agent 阅读画像

`USER.md` 是可删除、可重建的只读画像，JSONL 和记忆文件仍是正本。它只包含交接包中的目标、结果、下一步、项目、方向、非敏感且未归档的记忆，以及用户确认的当前阶段；不含财务。每行附原文件与记录 ID，生成头记录时间、发布端标识和来源指纹。正文约 1k token 的预算按 3000 UTF-8 字节控制，整行保留，更多资料读正本。

在一台指定的电脑上执行：

```sh
kaitu profile-publisher enable --dir <资料目录>
```

默认不自动指定任何电脑。建议指定每天整理的电脑；指定状态保存在既有本机状态目录的 `user-profile.json`，不进入同步、历史或备份。其他电脑正常写正本，既有后台刷新和保存版本流程会让发布端刷新画像。仅使用文件的 Agent 要留意生成时间；App 不运行时可手动执行 `kaitu profile-publisher refresh`。

换电脑时，先在原电脑 `profile-publisher disable`，等云盘同步完成，再在新电脑 `enable`。已有画像属于另一发布端时拒绝覆盖；未生成画像的设备也不会自行竞争发布权。云盘不提供跨设备原子锁，因此不要同时在两台尚未同步的电脑上指定发布端。

来源缺失、未下载或有同步冲突时撤下旧正文，只保留占位，来源恢复后自动重建。画像自身卸载不阻断正本写入、修改、删除、恢复或升级；画像不进版本历史、GitHub 备份、下载检查或格式校验。Agent 不能通过普通写工具修改画像，改动仍提议到 `inbox/agents/`。
