# 浏览器合成示例预览

拆分草稿依赖顺序：#211 合成状态 → #212 今天页与构建 → 本片资料和方向接线。官网接线与静态部署另开草稿，合并及上线前由主控核验；原 #210 保留作拆分前的证据索引。

这是现有 TestSite 的场景首页迭代，复用正式 App 的 LibraryPage、InboxPage、DirectionsPage、品牌与配色。首页布局与原创 SVG 插图采用 Opus 场景稿第 2 版（`claude/product-analysis-north-star-z6g5gu` 的 `842d1b86b1a0f794d0555478e30a634fed7e26fc`，`docs/design/home-scenes/index.html`），不另建网站。没有修改桌面入口、数据 schema 或官网 `gh-pages` 分支。

## 构建与本地查看

在仓库根目录安装已有依赖后运行：

```sh
pnpm --filter @kaitu/core build
pnpm --filter @kaitu/dsh-plugin build:testsite
python3 -m http.server 4894 --bind 127.0.0.1 --directory dist/site-preview
```

打开 `http://127.0.0.1:4894/testsite/`。产物只包含 `testsite/index.html` 与本地 CSS / JS，使用相对路径。官网部署草稿将整个 `testsite/` 目录复制到现有纯静态官网根目录，并从中英文首页进入；本源码系列不直接写 `gh-pages`。CSS / JS 使用内容哈希文件名。`?lang=zh-CN` / `?lang=en` 指定入口语言，未指定则跟随浏览器。`?state=pending` 可直接查看待确认示例。

## 体验范围

- 首页：三张场景卡分别打开同一个原文记录窗口、合成健康摘要和已有方向页；午饭只存原文，不估算营养，不声称已记入结构化饮食。健康数字明确标注合成，不读取设备，也不做分析。
- 换个 AI：勾选近况、预览完整复制内容，实际复制到剪贴板；没有自动发送。现有原文全部默认不勾选；合成示例资料包可直接试，健康和涉及他人的转写默认不勾选。剪贴板失败明确显示失败，也可手动选择预览复制。
- 手动贴回回答：先预览，再确认保存原文，保留空格和换行；不解析、不自动采纳建议。取消不保存。另有预先写好的待确认合成示例；确认保存后可查回，返回首页不重复提供已保存示例。
- 现在这件事：示例下一步可采纳、完成并记结果。
- 资料：搜索原文、目标与合成笔记正文，打开原文或笔记，查看收件箱。
- 开图：浏览正式方向页的合成示例。方向写入、AI 生成与文件选择明确说明需正式 App；足迹与资讯仍需正式 App，健康卡只提供上面的合成只读摘要。
- 中英文界面，跟随系统的浅深色，也可手动切换；示例内容保持原文。

仅使用浏览器 `sessionStorage` 下独立的 `kaitu:testsite:v1` 键，不使用真实开图工作区、服务端或共享状态。当前标签页刷新后保留，清除示例需先确认，取消不改资料；确认后在此键保存空白状态，不影响其他存储；浏览器恢复会话也可能恢复标签页状态。新独立标签页和另一浏览器会话从小林的合成种子资料开始，首页默认「有资料」。工具条可切换状态；「第一次打开」先确认清除，再展示真实空白记录；空白时切回「有资料」或「有待确认」会恢复合成种子资料；浏览器“复制标签页”可能复制最初状态，之后仍独立。请勿填写真实资料或密钥。

没有文件上传、系统文件读取、Key 输入、云盘连接、外部字体、地图服务、埋点或真实模型调用。HTML 的 CSP 禁止网络连接和表单外发；文件服务上下文显式替换为不可用，不能回落到正式本机接口。存储写入失败会显示错误，不显示已保存。

预览文件名沿用项目已有 standalone / build 脚本约定；合成状态是可丢弃的界面投影，不是工作区数据规范。
