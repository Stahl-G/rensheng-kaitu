# 浏览器合成示例预览

这是三个依赖草稿 PR 的组合入口。本切片仅含合成状态、浏览器状态行为测试与预览样式；打包和今天页在下一切片，资料与方向接线在最后一片。以下构建及完整体验说明适用于三个切片组合后。

组合入口复用正式 App 的 TodayTasks、LibraryPage、InboxPage、DirectionsPage、品牌与配色。没有修改桌面入口、数据 schema 或官网 `gh-pages` 分支。

## 构建与本地查看

在仓库根目录安装已有依赖后运行：

```sh
pnpm --filter @kaitu/core build
pnpm --filter @kaitu/dsh-plugin build:testsite
python3 -m http.server 4894 --bind 127.0.0.1 --directory dist/site-preview
```

打开 `http://127.0.0.1:4894/testsite/`。产物只包含 `testsite/index.html` 与本地 CSS / JS，使用相对路径。经另行批准后，可将整个 `testsite/` 目录复制到现有纯静态官网的根目录；本 PR 不包含发布工作流，不写 `gh-pages`，也不变更线上入口。

## 体验范围

- 今天：填写示例原文并保存，到资料或收件箱找回；采纳预写好的示例建议后完成，并记下一句示例结果。
- 资料：搜索原文、目标与合成笔记正文，打开原文或笔记，查看收件箱。
- 开图：浏览正式方向页的合成示例。方向写入、AI 生成与文件选择明确说明需正式 App；足迹、健康与资讯禁用。
- 中英文界面，跟随系统的浅深色，也可手动切换；示例内容保持原文。

仅使用浏览器 `sessionStorage` 下独立的 `kaitu:testsite:v1` 键，不使用真实开图工作区、服务端或共享状态。当前标签页刷新后保留，重置只清除此键；浏览器恢复会话也可能恢复标签页状态。新独立标签页和另一浏览器会话从种子资料开始；浏览器“复制标签页”可能复制最初状态，之后仍独立。请勿填写真实资料或密钥。

没有文件上传、系统文件读取、Key 输入、云盘连接、外部字体、地图服务、埋点或真实模型调用。HTML 的 CSP 禁止网络连接和表单外发；文件服务上下文显式替换为不可用，不能回落到正式本机接口。存储写入失败会显示错误，不显示已保存。

预览文件名沿用项目已有 standalone / build 脚本约定；合成状态是可丢弃的界面投影，不是工作区数据规范。
