# WIDE：展开后用满大屏（今天、资料、问问、开图）

仓库：`kaitu-ios`。依据：[product.md](../product.md) §4.2、[review-2026-10-18.md](../../design/iphone/review-2026-10-18.md)「切换仍然突兀」「第三轮：右栏方案」「材质」三节（用户已确认）。

## 问题

iPhone Duo 内屏上，今天、资料、问问三页还是窄屏那一栏（约 440pt）贴在左边，右边约 40% 是空的米色背景；开图页的地图在右侧状态栏下面留了一道约 90pt 的米色竖边。顶部胶囊写「电脑 22:10 更新」，今天页里又写「Dot 07:30 更新 · 1 条在路上」，两处说法不一致。

## 一条规则管四页

**展开 = 外屏整页原样变成右栏，左边多出来的地方放「窄屏里要点进去才看到的东西」。**

| 页面 | 右栏（外屏整页，同一个视图） | 左边 |
|---|---|---|
| 开图 | 面板：城市一排、接下来往哪走、今天最重要的一件事（外屏停在下半部，见 W4） | 地图满屏（内外屏都是） |
| 今天 | 最重要的一件事、接下来、你带来的规划 | 今天的安排（一排）+ 这一周（卡片） |
| 资料 | 搜索、分类、最近、各分类列表 | 选中那一项的全文 |
| 问问 | 对话和提问框 | 这次回答读过的资料全文；还没提问时是「可以这样问」 |

- 右栏宽度等于外屏宽度（按外屏实际宽度，不写死），展开时整列平移到右边，内容和滚动位置不变。
- 一样东西只出现一次：搬到左边的部分（今天的安排、这一周）在宽屏时从右栏里去掉。
- 没有选中项、没有数据时左边也不留白：资料默认选「最近」第一项；问问显示「可以这样问」；今天没有日程时那一排写「今天没有安排」，这一周照常。

为什么不照 Gemini 的方案把列表放左边：外屏整页 = 右栏是 10-18 用户确认的规则（开图页已按此做），四页都这样，展开时只是「左边多出一块」，右栏里没有任何东西重排，切换才连得上。

## 怎么写（结构）

沿用 review「切换仍然突兀 · 改法」：一个根视图，不用 `if wide { A } else { B }`、不用 `TabView` / `NavigationSplitView` 二选一。

```swift
/// 四页共用。窄屏只有右栏占满；宽屏左边出现，右栏固定为外屏宽度。
struct PageSplit<Detail: View, Column: View>: View {
    let wide: Bool
    let columnWidth: CGFloat          // 外屏宽度，由根视图传入
    @ViewBuilder var detail: Detail   // 左边
    @ViewBuilder var column: Column   // 外屏整页

    var body: some View {
        HStack(spacing: 0) {
            if wide { detail.frame(maxWidth: .infinity, maxHeight: .infinity) }
            column.frame(width: wide ? columnWidth : nil)
        }
    }
}
```

- `if wide { detail }` 放在 `column` 前面不会改变 `column` 的身份（同一个位置、同一个类型），右栏不重建、滚动位置保留。不要把 `column` 写进 if 的两个分支里。
- 右栏里搬走的段落用参数控制：`TodayColumn(wide: wide)` 在宽屏时不画「今天的安排」和「这一周」。
- 左右两边各自滚动。尺寸变化时只改排法，不重新读快照、不重新算（review 第 5 条）。
- 内容是不透明的白卡，不用玻璃；玻璃只给浮在上面的顶部胶囊、状态位、记一下、地图上的右栏卡片（review「材质」）。

## W1 今天

左边从上到下（左右边距 24，段间距 28）：

**今天的安排**：按时间排成一行的卡片，放不下就换行（不按时间比例画，标题能读全）。

```
今天的安排                                         现在 00:10
[10:00–11:00 周会] [15:00–16:30 外景拍摄 · iPhone 日历] [20:00–21:00 整理摄影集 · 待确认  加进日历 | 不要]
```

- 已确认的日程：白卡、藏青左边线；已经过去的调淡（`#6B6A66` 文字）。
- 待确认的建议：虚线描边（`#2B4C7E`），卡片里两个按钮「加进日历」「不要」，点按区域不小于 44pt；行为和现在右栏里的一样（手机写日历、交操作）。
- 「现在」竖线插在当前时间前后两张卡之间；不是今天的快照不画。
- 数据：`today.json` 的 `blocks` 和 `proposals`。

**这一周 · 10月13日 – 19日**：自适应网格（`LazyVGrid(columns: [.adaptive(minimum: 220)])`），卡片：

- 每个进行中项目一张：标题；7 天小柱（`week.json` 的 `projects[].daily`，有字数用字数，否则用提交数）；合计一行「本周 1,240 字」或「本周 23 次提交」；「下一步：…」（`projects[].next[0]`）。
- 健康一张：训练 3 次（3 天）、平均睡眠 6.8 小时、平均蛋白 92 g、体重 71.6 kg（10-18）。没有的项不写，不写 0。
- 原文一张：这周记下 5 条。
- 最近的变化：最多 3 行「时间 · 说明」（`week.json` 的 `changes`）。
- `week.json` 的生成者或日期和今天的不同时，标题右边一行小字「电脑 10-16 的数据」（I11）。

右栏：标题（日期 + 今天）、最重要的一件事、接下来、你带来的规划。状态行在宽屏不显示（见 W4）。

## W2 资料

依赖 IOS-1（读 `phone/library.json`）。

- 右栏 = 外屏的资料页：搜索、分类胶囊（全部 / 项目 / 健康 / 原文 / 我的）、最近、各分类列表。宽屏时点一行只改选中项，不压栈；窄屏照旧推进详情页（同一个详情视图）。
- 左边 = 选中项的详情，默认选「最近」第一项；选中行在右栏里高亮。
- 详情顶部：分类 · 日期，标题 22 号粗体。正文按分类：
  - 原文：去掉 frontmatter 的全文，可选中复制；路径在 `inbox/notes/done/` 下写「已整理」，否则「等电脑整理」。
  - 项目：`STATUS.md` 的阶段、下一步列表，再接正文（`AttributedString(markdown:)` 即可）。
  - 健康：那个月的记录文件，同一 id 取 rev 最大的一行，新的在上，每行「日期 时间 · 两三个关键字段」。
  - 我的 · 目标（`me/goals.json` + `id`）：标题、下一步、记过几次结果（取 `today.json` 的 `goals`）。
  - 我的 · 记忆：正文。
- 点了才读文件，读过的按路径缓存在内存里，`library.json` 的 `generated_at` 变了就清掉。读的时候详情区立刻显示「正在读…」，读不到写原因（离线、文件还没下载、没有权限），不弹窗。
- 页尾一句「财务和标为敏感的记忆只在电脑上看。」保留。
- 没有 `library.json`（电脑还是旧版）：右栏写「电脑上的开图更新后，这里会列出资料」，左边不显示。

## W3 问问

只在 Debug 构建里出现（首发不带问问，见 IOS-3）。

- 右栏 = 外屏的问问页：对话、来源标签、建议卡、提问框。历史对话放在右栏标题旁的按钮里（窄屏弹出列表，宽屏弹出浮层），不单独占一栏。
- 左边：当前回答读过的资料，点回答下面的来源标签切换显示哪一份（详情视图和资料页共用）。
- 还没提问时左边显示：
  - 「可以这样问」3–5 条，从快照里拼出来，不调用 AI：「『把摄影集初选从 80 张挑到 30 张』怎么开始？」（今天第一项）、「这周训练够了吗？」（这一周有训练时）、「『年底出一本摄影集』进展到哪了？」（第一个目标）。点一下填进提问框，不自动发送。
  - 「能读：今天、这一周、开图和资料目录里的文件。读不到：财务、标为敏感的记忆、Key。发给：DeepSeek（你填的 Key）」；没填 Key 时最后一句换成「还没填 Key，可以先在原来的 AI 里继续」。

## W4 开图：内外屏都是满屏地图，面板从下边移到右边；状态只留一处

外屏现在是「滚动页面里一张约 160pt 高的小地图 + 竖排城市 + 卡片」，内屏是「满屏地图 + 右侧浮层」，两套结构；外屏小地图还停在汕头、高雄一带的海面上，看不到路线。改成内外屏同一个结构（这一条更新了 `Map.dc.html` 的外屏做法，以本节为准）：

- **地图永远满屏、只有一个实例**：外屏、内屏都铺满整个屏幕，包括右侧状态栏下面那一条（地图那一层 `.ignoresSafeArea()`）。删掉外屏滚动页里的小地图。
- **面板是同一个视图，只换停靠位置**：外屏停在下半部（约占 48% 高，内容在面板里滚动），内屏停在右边（宽度 = 外屏宽度，就是前面说的右栏）。面板内容不变：城市一排（横向一排，可横滑，不竖排）、接下来往哪走、今天最重要的一件事、「这一周」链接。面板是玻璃材质。
- **地图让出面板的位置再取景**：取景范围 = `map.json` 的全部地点和路线点；四周留白 = 面板占掉的那一边（外屏是底部面板高度，内屏是右侧面板宽度）再加 24pt。用 `MKMapView.setVisibleMapRect(_:edgePadding:animated:)`（或 SwiftUI `Map` 的 `safeAreaPadding` 加相机位置）。地图外框或面板位置一变就重新取景，不只在第一次加载时做（这是现在外屏看不到路线的原因，review「原因」第 3 条）。
- 顶部胶囊、状态位、面板按安全区摆放；苹果地图的标识和法律链接用 `layoutMargins` 挪到不被挡的位置（review W5）。
- 底部浮着的「记一下」和标签栏不能盖住面板或列表的最后一行：滚动内容加 `safeAreaInset(edge: .bottom)` 留出它们的高度（今天、资料页同理）。
- 右栏底部的「这一周与全部信息」改成「这一周」，点了切到今天页并停在「这一周」（宽屏就是左边那块）。原来的「全部信息」二级页删掉，它的内容现在都在今天页里。
- **状态只留一处**（review P3）：宽屏只在右上角状态位显示，窄屏只在页面标题下面显示，同一时间不会两处都有。资料页、问问页标题下面的「Dot 07:30 更新」在宽屏也去掉。
- **说法只有一个来源**：状态位和状态行都读同一个计算属性，内容来自 `today.json` 的 `generator` 和 `generated_at`，加上在路上的条数（product §5 状态文案）。截图里「电脑 22:10」和「Dot 07:30」并存，是两处各读了不同的东西，改成一处算、两处用。

## 不要做

- 不用 `GeometryReader` + `if sizeClass == .regular || width > 620 { HStack } else { VStack }` 这类写法（Gemini 给的骨架就是这样）：展开时两个分支互换，整棵树重建，正是 review 里说的「切换突兀」的原因。
- 不按机型写死尺寸；只看系统给的宽度和外屏宽度。
- 不加新的数据格式；左边的内容全部来自现有的 `today.json`、`week.json`、`map.json`、`library.json` 和点开时读的文件。
- 不在左边加快照里没有的数字（例如「已筛 45/80 张」这种需要新字段的进度）。
- 不为宽屏另写一套卡片：这一周的卡片窄屏、宽屏共用一个视图，只是排法不同。

## 验收

- iPhone Duo 模拟器内屏横竖两个方向、外屏、普通 iPhone（iPhone 17 Pro）各截今天、开图、资料三页（Debug 再加问问），中英文各一套，放进 PR；宽屏上任何一页右边或左边都没有大块空白。
- 慢速动画下展开、合上各三次录屏：右栏内容和滚动位置不变，左边是「长出来」的；开图页地图不闪、不重新加载。
- 今天页宽屏：待确认的建议在左边一行里点「加进日历」，行为与原来一致，回执回来后变成已确认。
- 资料页：点 20 个不同项目，每次 0.1 秒内有反馈（「正在读…」或内容），读过的再点立刻显示。
- 状态：今天快照由 Dot 生成时，宽屏状态位和窄屏状态行都显示「Dot 07:30 更新」，不出现第二种说法。
