# ASK-4：问问页、卡片和设置

规范：[../ask.md](../ask.md) §5、§7。设计：`docs/design/iphone/Ask.dc.html`。依赖 ASK-2、ASK-3。仓库：`kaitu-ios`。

## 目标

把问问接到第四个标签上，按设计稿显示步骤、回答、来源和建议卡片；用户点了卡片才写收件箱。

## 做什么

1. 问问页：顶部「DeepSeek · 你的 Key」，对话列表，底部提问框加按住说话；回答上方显示当前步骤，下面显示来源标签（点开看原文）。
2. 建议卡片：「放进待确认」写收件箱文件（`ios-<设备号>-<ULID>` 命名，`origin: assistant`），走现有离线队列；写完卡片显示「已放进待确认 · 等 Dot 处理」或「等电脑处理」（按 today.json 的 generator）。「不用」只关卡片。
3. 停止按钮：生成中随时可点，0.3 秒内停下。
4. 错误：照 ASK-1 的五类错误显示一句话加「去设置」；切后台被中断显示「回答被中断」和「继续」。
5. 设置 › 问问：选服务商、填 Key（钥匙串）、测试连接、写明「问题和读到的资料会发给 <服务商>」；没有 Key 时问问页显示填 Key 的入口，和「在原来的 AI 里继续」（分享资料包，见 product §4.5）。
6. 对话存在 App 容器里，可以清空；不同步、不写进资料位置。

## 不要做

- 不在本地整理原文、不替用户确认任何卡片。
- 不写死字号和颜色，照 `docs/design/iphone/review-2026-10-18.md` 开头三条规则。
