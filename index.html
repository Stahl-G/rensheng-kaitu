常见问题

这个网站会读取我的资料吗？

不会。这是项目官网，截图和体验站用的都是虚构人物「小林」的合成资料，不连接你的资料文件夹。网站不放统计和第三方脚本；只有下载信息会向 GitHub 查询最新版本。

必须用某一个 AI 吗？

不用。可以填 DeepSeek、OpenAI、Claude、Gemini、Kimi、智谱等任一服务的 Key 用内置问问，添加过的服务都会保留，随时切换；也可以不填 Key，把资料包复制给你常用的 AI，再把回答贴回来。

免费吗？开源吗？

免费。代码以 MIT 许可证开源，在 GitHub。

这是正式版吗？

还不是。当前是 0.1.4-rc.2，发布候选版，在 GitHub 上标为预览版。

是。当前是 0.1.4-rc.2 正式版。

有 Windows 版吗？

Windows 使用 DeepSeek Harness（DSH）开图插件，Linux 和 Intel Mac 也可使用。安装步骤见下载页。

有 iPhone 版吗？

正在准备上架 App Store。

有英文界面吗？

有。界面语言默认跟随系统，也可以在「右上角头像 → 设置」里改成中文或 English。

我的资料存在哪里？

第一次打开时先选资料放哪：这台电脑（默认 ~/kaitu-ai-memory），或 iCloud、Google Drive、坚果云、其他同步盘的文件夹。只有启用相应的同步方式，资料才会同步到所选存储服务。版本历史和 Key 留在这台电脑。哪些内容会发给 AI，见资料去向。
