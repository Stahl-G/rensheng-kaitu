    示例资料

    今天

    最重要的一件事、你带来的规划、最多三条下一步，和要你确认的事。

    开图

    健康、足迹、资讯、方向，打开先看健康。

    资料

    日程、在做的事、健康、财务、笔记与决策、收件箱，都在这里查。

    问问

    内置 AI 对话。添加一个 AI 服务，它能读你的资料来回答。

    打开 JavaScript 后，这里是一个可以点击的开图示例。

    健康

    目标、本周训练与饮食、健康的下一步。

    足迹

    从家乡出发，把去过的城市和经历连在地图上。

    资讯

    按你关注的方向收集资讯，可以标「有用」或「不相关」。

    方向

    一条一行：为什么在意，第一步做什么；再记下尝试和正反依据。

    怎么用

    把记录留下来，把事情做下去。

    1. 1

      搬进来就看得见

      先选资料放哪：这台电脑，或 iCloud、Google Drive、坚果云。再从 ChatGPT、Claude、Gemini、豆包等常用的 AI 搬来记忆，或贴一段聊过的对话。逐条确认后，目标出现在今天页，标明来自哪里，不用填 Key。

    2. 2

      每周往前走一步

      每个目标定一个下一步。做完记一句实际结果；做不了就改到以后，或写下为什么暂停。

    3. 3

      换个 AI 也接得上

      把近况打包复制给常用的 AI，回答贴回开图，核对后再更新。问问里可以添加多个 AI 服务，随时切换。Claude、Codex 等本机客户端可以通过 MCP 直接读写；Grok 等能连 Google Drive 的 AI 可以接力。

    每周往前走

    每个目标都落到一个下一步和一条真实结果。健康页的「近 5 周」把这几周的训练排成格子：哪天练了、练了多少，一眼看清。

    示意：小林的示例资料，不是真实用户数据。

    资料

    资料放在自己的文件夹里。

    全是 Markdown 和 JSON，任何编辑器都能打开。每次写入都存一个版本，改错了能恢复。

    资料可以只放在这台电脑，也可以同步到 iCloud、Google Drive、坚果云或其他同步盘；版本历史和 Key 始终留在这台电脑。

    灵感

    灵感来源

    孙学、薄肌、黄毛理论……在邵艾伦与孙宇晨那场广受争议的四小时访谈中，这三个听起来玄乎其玄的概念，被拼成了一套关于认知、身体和行动的人生方法论。

    有意思的是，访谈里最具体的部分，恰恰是我们已经开始在日常生活中使用 AI 的方式。

    把饭前饭后的照片交给 Claude 计算热量，用 Oura 戒指记录睡眠，让 AI 整理训练视频、追踪重量和组数，每天生成一份报告。所有记录保存在本地 Markdown 文件中，换一个 Agent，依然可以接着使用。

    我们已经习惯了把越来越多的事情交给 AI：写作时讨论故事情节，换工作时分析职业选择，旅行前规划路线，遇到难题时一起寻找答案。

    聊得多了，AI 知道我们做过什么、想做什么、犹豫过什么。可这些信息散落在不同的聊天记录里。上个月制定的计划后来怎么样了？当初为什么放弃一个机会？最近有哪些事情始终没有推进？想知道答案，往往还得重新翻聊天记录。

    我们由此想到，如果把这些散落的信息整理出来，是不是就能得到一张属于自己的人生进度图？

    走过的路可以回看，接下来要去哪里，则像游戏里开地图一样，由自己决定。

    常见问题

    这个网站会读取我的资料吗？

    不会。这是项目官网，页面里的界面都是示例资料，不连接你的资料文件夹。网站不放统计和第三方脚本；只有下载页会向 GitHub 查询最新版本。

    必须用某一个 AI 吗？

    不用。可以填 DeepSeek、OpenAI、Claude、Gemini、Kimi、智谱等任一服务的 Key 用内置问问，添加过的服务都会保留，随时切换；也可以不填 Key，把资料包复制给你常用的 AI，再把回答贴回来。

    免费吗？开源吗？

    免费。代码以 MIT 许可证开源，在 GitHub。

    这是正式版吗？

    还不是。当前是 0.1.0-rc.4，发布候选版，在 GitHub 上标为预览版。

    是。当前是 0.1.0-rc.4 正式版。

    有 Windows 版吗？

    有，直接下载 Windows EXE 安装包，安装后在「问问」添加 API Key 即可使用。Linux 和 Intel Mac 仍可用 DSH 插件。步骤见下载页。

    有英文界面吗？

    有。界面语言默认跟随系统，也可以在「右上角头像 → 设置」里改成中文或 English。

    我的资料存在哪里？

    第一次打开时先选资料放哪：这台电脑（默认 ~/kaitu），或 iCloud、Google Drive、坚果云、其他同步盘的文件夹。选了云盘才会同步；版本历史和 Key 始终留在这台电脑。哪些内容会发给 AI，见资料去向。
