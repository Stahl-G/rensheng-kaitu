愿景

你的 Agent 们共用的一本账。

2026 年，常驻在云端、替人办事的 Agent 接连出现：它们读邮件、排日程，在你离开后接着做事。你很可能同时用好几个，再加上电脑上的、手机里的。每一个都在记你——你的目标、习惯、手上的事。可它们记的各是各的，互不相通，也大多锁在各家的服务里：你看不全，也改不了。

开图做那一本账

开图不做又一个 Agent。它是一个归你所有的文件夹：目标、下一步、日程、记录、记忆、走过的路，都是人能读、Agent 也能读的 Markdown 和 JSON。

  • 是你的。放在你选的地方：这台电脑、你的 iCloud、你自己的 GitHub 仓库。开图没有服务器，看不到你的资料。
  • 谁都能接。电脑上的 Agent、云端的常驻 Agent、手机上的问问，读同一份规则，按同一种格式交接。换一个 Agent，账还在。
  • 看得见，改得了，撤得回。每条记忆都是一个文件，你可以打开、修改、删除；每次改动都有版本，可以退回；谁写了什么，都有记录。
  • 该你定的，留给你。确认阶段、启用方向、写进日历这类决定，Agent 只能提建议，由你点头。

给你看的那一面

这本账不只给 Agent 用。开图把它画成你每天会看一眼的样子：今天最重要的一件事，这一周做了什么，人生走到了哪。合上管今天，展开看人生。

我们会坚持的

  • 资料格式公开，不加密、不私有，随时能整份带走。
  • Agent 接手的规则公开、带版本号，任何 Agent 都可以照着接入。
  • 不做广告，不卖数据。
  • 代码开源。

人生开图生活，逐渐清晰。
