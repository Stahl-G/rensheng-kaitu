开发者：一句话建好开图工作区

给已经在用 Claude Code、Codex、Cursor 这类编程 Agent 的人。不用装 App，Agent 帮你在自己的 GitHub 上建好私有的开图工作区，换电脑、换 Agent 都能接着做。

一句话开始#

把这句话交给你的 Agent：

帮我按 https://github.com/Stahl-G/rensheng-kaitu/blob/main/docs/guides/agent-memory/INSTALL.md 建立我的开图记忆，直接做完。

任何能操作文件和终端的 Agent 都行。本机需要 git 和 GitHub 官方命令行 gh；还没登录时，Agent 会带你去 GitHub 官方页面登录。

它会做什么#

  1. 检查 git、gh 和登录状态。这台电脑上已经有开图资料，就用原来那份，不建第二份。
  2. 问你最多三个问题，第一个是「除了眼前这件事，你最近还在推进什么」，不只围着当前目录里的项目。
  3. 你提到的每个项目，它自己读最新的文档、提交和开着的 PR，写出做到哪、卡在哪、下一步，并注明读到哪天。
  4. 把要保存的内容给你看一次，你确认后建私有仓库 kaitu-ai-memory 并上传。
  5. 写下第一份交接，最后给你一段话，贴给另一台电脑或另一个 Agent 就能接上。

它不会做的#

  • 不建公开仓库；每次推送前核对仓库是私有的。
  • 不动你已有的仓库和文件。
  • 不问你要密码、token 或验证码，登录只走 GitHub 官方页面。
  • 你确认之前不上传。

换电脑或换 Agent#

请按 https://github.com/Stahl-G/rensheng-kaitu/blob/main/docs/guides/agent-memory/ADD_DEVICE.md 接上我的开图私人记忆 <仓库地址>，读完告诉我你记住了什么，然后接着做我交代的事。

新 Agent 读完先告诉你它记住了什么。干完活，它更新做过的那个项目的进度，再留一份交接；档案、偏好和目标它只提建议，等你确认。

工作区里有什么#

kaitu-ai-memory/
├── AGENT-README.md      Agent 从这里读起
├── me/                  档案、目标、作息规则
├── memory/              偏好、事实、决定
├── projects/<项目>/     STATUS.md · log.md
├── handoffs/            每次干完活的交接
├── inbox/agents/        还没采纳的建议
└── kaitu-backup.json    开图 App 靠它认出这个仓库

都是普通的 Markdown 和 JSON，格式和开图 App 一样，你随时能看、能改。

在 App 里看#

装上开图（见下载）后，在「设置 → GitHub 同步」从这个仓库恢复到一个新文件夹，就能在今天、开图、资料几页里看到同一份资料。

Agent 照着做的完整步骤：INSTALL.md · ADD_DEVICE.md · 指南首页。
