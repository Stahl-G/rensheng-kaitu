# 人生开图

照孙宇晨 × 邵艾伦访谈里的方法，把你的生活全部 AI 化。

孙宇晨说，他把吃饭、训练、睡眠、学习全部交给 AI 管：拍照记饮食、Oura 戒指读睡眠、AI 每天出日报。**开图**把这套做法做成了一个开源工具：所有数据放在你自己电脑上的一个文件夹里，任何 Agent 读了就知道你在做什么、下一步该做什么。

> 灵感来自邵艾伦 × 孙宇晨的访谈。本项目为独立开源项目，与二人及其公司无关联。
