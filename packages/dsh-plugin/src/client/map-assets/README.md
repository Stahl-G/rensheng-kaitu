# Local map assets

`ne_110m_countries.json` is GeoJSON from Natural Earth's 1:110m Admin 0 Countries dataset:
https://github.com/nvkelso/natural-earth-vector/blob/ca96624a56bd078437bca8184e78163e5039ad19/geojson/ne_110m_admin_0_countries.geojson

Feature properties are removed; geometries are unchanged. Natural Earth raster and vector data are public domain:
https://www.naturalearthdata.com/about/terms-of-use/

The browser demo bundles this vector outline and loads no remote map tiles. Existing product map attribution is retained.
