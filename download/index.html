安装包来自 GitHub Releases。这是发布候选版，还不是正式版。

安装

  1. 打开下载的 Kaitu.dmg。
  2. 把 Kaitu.app（人生开图）拖进「应用程序」。
  3. 在「应用程序」里双击打开。第一次打开先选资料放哪：这台电脑（默认 ~/kaitu）、iCloud、Google Drive、坚果云或其他同步盘的文件夹。

macOS 不让打开时

这一版的发布说明写明安装包已用 Developer ID 签名并经苹果公证，一般可以直接打开。如果 macOS 仍提示无法打开或无法验证开发者：打开「系统设置 → 隐私与安全性」，在页面下方找到关于 Kaitu 的提示，点「仍要打开」，再确认一次。

需要什么

  • Kaitu.app 需要一台 Apple 芯片（arm64）的 Mac；Intel Mac、Windows 和 Linux 用 DeepSeek Harness 插件。
  • 看资料、记原文、看地图和财务都不需要 API Key。想用内置问问，再添加一个 AI 服务：DeepSeek 默认推荐，也可以用 OpenAI、Claude、Gemini、Kimi、智谱等。

Windows 和 Linux：装进 DeepSeek Harness

Windows 和 Linux 上，开图以 DeepSeek Harness（DSH）插件的形式使用，目前是试用支持。装好后 DSH 侧栏多出「开图」，有今天、开图、资料三个入口；对话用 DSH 自己的会话。

  1. 装好 DeepSeek Harness 桌面版，版本 0.2.1-rc.2 或更新（见 DeepSeek Harness 的 GitHub）。打开一次，在「设置 → 模型」配好模型。
  2. 打开侧栏「插件」，安装 kaitu-dsh。
  3. 装好后重开 DSH，侧栏点「开图」。第一次打开先选资料放哪。

也可以从插件市场装：在「插件」点「实验性插件」旁的「更多」，打开「自定义插件市场」；在「发现」里点「添加索引源」，填 https://kaitu.si/plugins/index.json，再安装「人生开图」。

习惯命令行的话（需要 Node.js 22.19+ 或 24+）：

npm install -g rensheng-kaitu@next --allow-scripts=@deepseek-ai/dsh-subprocess-local,koffi,node-pty
kaitu dsh --install

运行后重开 DSH。同一个资料文件夹也在 Mac 上的 Kaitu.app 里用时，加 --no-automation，后台任务只在 Kaitu.app 里跑。写入系统日历只在 Mac 的 Kaitu.app 里可用，其他环境会生成日历文件让你导入。

其他方式

命令行与网页版

同一个版本也有命令行与网页版安装包：rensheng-kaitu-0.1.0-rc.3.tgz（SHA-256 628977878b48b1451bf364074ef1ddbdda40c0f6bbd2e2bcc5cdc58a7f1cf412）。需要 Node.js 22.19+（22 系列）或 24+。不需要 Kaitu.app，也不需要另装 DSH。

npm install -g rensheng-kaitu@next --allow-scripts=@deepseek-ai/dsh-subprocess-local,koffi,node-pty
kaitu init ~/kaitu-web
kaitu --dir ~/kaitu-web ui

工作台只在本机（127.0.0.1）打开；打开命令输出的地址，在「问问 → 连接 AI」里添加 AI 服务。

从源码运行

需要 Node.js 22.19+（22 系列）或 24+，以及 pnpm。

git clone https://github.com/Stahl-G/rensheng-kaitu.git
cd rensheng-kaitu
pnpm install
pnpm build
node packages/cli/dist/main.js init ~/kaitu-demo --sample
node packages/cli/dist/main.js --dir ~/kaitu-demo ui

--sample 会生成合成的演示资料。

安装包都发布在 GitHub Releases。安装以后怎么用，见文档；资料存在哪、发给谁，见资料去向。
