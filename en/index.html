FAQ

Does this website read my notes?

No. This is the project website. The screenshots and the browser demo use synthetic notes for a fictional person, Lin, and aren't connected to your notes folder. There are no analytics or third-party scripts; only the download details ask GitHub for the latest version.

Do I have to use a particular AI?

No. Add a key for DeepSeek, OpenAI, Claude, Gemini, Kimi, Zhipu or another service to use Ask; every service you add is kept, so you can switch. Or skip keys entirely: copy a context pack to the AI you already use and paste its answer back.

Is it free? Is it open source?

Free. The code is open source under the MIT License, on GitHub.

Is this a stable release?

Not yet. The current version is 0.1.4-rc.2, a release candidate marked as a pre-release on GitHub.

Yes. The current version is 0.1.4-rc.2.

Is there a Windows version?

On Windows, install the Kaitu plugin in DeepSeek Harness (DSH). Linux and Intel Macs use the same plugin. See the download page.

Is there an iPhone app?

It's getting ready for the App Store.

Is the app available in English?

Yes. The interface follows your system language by default, and you can switch between 中文 and English in Settings (avatar menu, top right).

Where are my notes stored?

The first time you open Kaitu, you choose where your notes live: this computer (~/kaitu-ai-memory by default), iCloud, Google Drive, Nutstore, or a folder another sync app syncs. Nothing syncs unless you pick a cloud drive, and version history and keys always stay on this computer. For what is sent to an AI, see Where your data goes.
