Install

  1. Open the downloaded Kaitu.dmg.
  2. Drag Kaitu.app (shown as 人生开图) into Applications.
  3. Double-click it in Applications. The first time, choose where your notes live: this computer (~/kaitu by default), iCloud, Google Drive, Nutstore, or a folder another sync app syncs.

If macOS won't open it

The release notes for this version say the app is signed with a Developer ID and notarized by Apple, so it should open normally. If macOS still says it can't open the app or verify the developer, go to System Settings → Privacy & Security, find the message about Kaitu near the bottom, click Open Anyway, and confirm.

What you need

  • A Mac with Apple silicon (arm64). There's no Intel Mac or Windows version yet.
  • No API key is needed to browse your notes, jot things down, or view maps and finances. To use the built-in Ask, add an AI service: DeepSeek is the default suggestion, and OpenAI, Claude, Gemini, Kimi, Zhipu and others also work.

Other ways

CLI and web version

The same version also ships as a CLI and web package: rensheng-kaitu-0.1.0-rc.3.tgz (SHA-256 628977878b48b1451bf364074ef1ddbdda40c0f6bbd2e2bcc5cdc58a7f1cf412). It needs Node.js 22.19+ (22.x) or 24+, and doesn't need Kaitu.app or a separate DSH install.

npm install -g https://github.com/Stahl-G/rensheng-kaitu/releases/download/v0.1.0-rc.3/rensheng-kaitu-0.1.0-rc.3.tgz --allow-scripts=@deepseek-ai/dsh-subprocess-local,koffi,node-pty
kaitu init ~/kaitu-web
kaitu --dir ~/kaitu-web ui

The workbench only listens on this computer (127.0.0.1). Open the address it prints, then add an AI service in Ask → Connect AI. It isn't published to npm yet.

Run from source

You need Node.js 22.19+ (22.x) or 24+, and pnpm.

git clone https://github.com/Stahl-G/rensheng-kaitu.git
cd rensheng-kaitu
pnpm install
pnpm build
node packages/cli/dist/main.js init ~/kaitu-demo --sample
node packages/cli/dist/main.js --dir ~/kaitu-demo ui

--sample creates synthetic demo notes.

Add it to DeepSeek Harness

If you already use the DeepSeek Harness 0.2.1-rc.1 desktop app: after pnpm build in the source folder, run the command below and reopen DeepSeek Harness. Kaitu appears in the sidebar with three tabs: Today, Explore and Library. DSH keeps its own brand and panels, and chats use DSH's own sessions. If Kaitu.app uses the same notes folder, add --no-automation.

node packages/cli/dist/main.js dsh --install

Every build is published on GitHub Releases. For how to use it, see the docs; for where your notes are stored and sent, see Where your data goes.
