Run the EXE to install, then open Kaitu. Node and DSH are included; no developer tools are needed. This Windows preview is not digitally signed, so Windows may show a publisher verification notice.

Choose a notes folder on first launch. In Ask → Connect AI → Use Kaitu's AI, enter an API key, fetch the model list and choose a model. DeepSeek is recommended; other providers are available.

Install on Mac

  1. Open the downloaded Kaitu.dmg.
  2. Drag Kaitu.app (shown as 人生开图) into Applications.
  3. Double-click it in Applications. The first time, choose where your notes live: this computer (~/kaitu by default), iCloud, Google Drive, Nutstore, or a folder another sync app syncs.

If macOS won't open it

The release notes for this version say the app is signed with a Developer ID and notarized by Apple, so it should open normally. If macOS still says it can't open the app or verify the developer, go to System Settings → Privacy & Security, find the message about Kaitu near the bottom, click Open Anyway, and confirm.

What you need

  • Use the EXE above on Windows. Kaitu.app needs a Mac with Apple silicon (arm64). On Intel Macs and Linux, use the DeepSeek Harness plugin.
  • No API key is needed to browse your notes, jot things down, or view maps and finances. To use the built-in Ask, add an AI service: DeepSeek is the default suggestion, and OpenAI, Claude, Gemini, Kimi, Zhipu and others also work.

Alternative: add Kaitu to DeepSeek Harness

As an alternative on Windows, Linux and Intel Macs, Kaitu runs as a DeepSeek Harness (DSH) plugin. Support is in preview. Once installed, DSH gets a Kaitu entry in its sidebar with three tabs, Today, Explore and Library, and chats use DSH’s own sessions.

  1. Install the DeepSeek Harness desktop app, version 0.2.1-rc.2 or later (see DeepSeek Harness on GitHub). Open it once and set up a model in Settings → Models.
  2. Open Plugins in the sidebar and install kaitu-dsh.
  3. Reopen DSH and click Kaitu in the sidebar. The first time, choose where your notes live.

You can also install it from a plugin market: in Plugins, click More next to Experimental plugins and turn on Custom plugin market; under Discover, click Add index source, enter https://kaitu.si/plugins/index.json, then install Kaitu.

If you prefer the command line (Node.js 22.19+ or 24+):

npm install -g rensheng-kaitu@next --allow-scripts=@deepseek-ai/dsh-subprocess-local,koffi,node-pty
kaitu dsh --install

Then reopen DSH. If Kaitu.app on a Mac uses the same notes folder, add --no-automation so background tasks only run in Kaitu.app. Writing to the system calendar only works in Kaitu.app on a Mac; elsewhere Kaitu creates calendar files for you to import.

Other ways

CLI and web version

The same version also ships as a CLI and web package: rensheng-kaitu-0.1.0-rc.4.tgz (SHA-256 a3fb91a302dab8dd9adc8ffe03e7a6c890449019e6bbad0d82278ea85bb1cbc3). It needs Node.js 22.19+ (22.x) or 24+, and doesn't need Kaitu.app or a separate DSH install.

npm install -g rensheng-kaitu@next --allow-scripts=@deepseek-ai/dsh-subprocess-local,koffi,node-pty
kaitu init ~/kaitu-web
kaitu --dir ~/kaitu-web ui

The workbench only listens on this computer (127.0.0.1). Open the address it prints, then add an AI service in Ask → Connect AI.

Run from source

You need Node.js 22.19+ (22.x) or 24+, and pnpm.

git clone https://github.com/Stahl-G/rensheng-kaitu.git
cd rensheng-kaitu
pnpm install
pnpm build
node packages/cli/dist/main.js init ~/kaitu-demo --sample
node packages/cli/dist/main.js --dir ~/kaitu-demo ui

--sample creates synthetic demo notes.

Every build is published on GitHub Releases. For how to use it, see the docs; for where your notes are stored and sent, see Where your data goesiPhone privacy.
