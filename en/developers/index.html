For developers: set up a Kaitu workspace in one sentence

For people who already use coding agents like Claude Code, Codex or Cursor. No app needed: your agent creates a private Kaitu workspace in your own GitHub account, so you can pick up where you left off on any computer, with any agent.

Start with one sentence#

Give this to your agent:

Set up my Kaitu memory by following https://github.com/Stahl-G/rensheng-kaitu/blob/main/docs/guides/agent-memory/INSTALL.md. Do it end to end, don't just give me instructions.

Any agent that can work with files and a terminal will do. You need git and GitHub's official CLI, gh. If you are not signed in, the agent sends you to GitHub's own sign-in page.

What it does#

  1. Checks git, gh and your sign-in. If this computer already has Kaitu data, it uses that instead of making a second copy.
  2. Asks you at most three questions. The first is always "Besides this, what else are you working on?", so it does not stop at the project in the current folder.
  3. For every project you mention, it reads the latest docs, commits and open PRs itself, and writes where it stands, what is blocking it and what comes next, with the date it read them.
  4. Shows you what it will save. After you confirm, it creates the private repository kaitu-ai-memory and uploads.
  5. Writes the first handoff and gives you a sentence to paste into another computer or agent.

What it will not do#

  • Create a public repository. It checks the repository is private before every push.
  • Touch your existing repositories or files.
  • Ask for passwords, tokens or codes. Sign-in only happens on GitHub's own page.
  • Upload anything before you confirm.

Another computer or another agent#

Connect to my Kaitu memory at <repo URL> by following https://github.com/Stahl-G/rensheng-kaitu/blob/main/docs/guides/agent-memory/ADD_DEVICE.md. Tell me what you remember, then continue with what I ask.

The new agent first tells you what it remembers. When it finishes work, it updates the progress of the project it worked on and leaves a handoff. Your profile, preferences and goals it only suggests changes to, and waits for you.

What is in the workspace#

kaitu-ai-memory/
├── AGENT-README.md      agents start here
├── me/                  profile, goals, routines
├── memory/              preferences, facts, decisions
├── projects/<project>/  STATUS.md · log.md
├── handoffs/            a handoff after each session
├── inbox/agents/        suggestions not yet accepted
└── kaitu-backup.json    lets the Kaitu app recognize it

Plain Markdown and JSON in the same format as the Kaitu app. You can read and edit them any time.

See it in the app#

After installing Kaitu (see Download), open Settings → GitHub sync and restore from this repository into a new folder. The same data then shows up in Today, Map and Library.

The full steps your agent follows: INSTALL.md · ADD_DEVICE.md · guide. The guide is written in Chinese; agents read it fine.
